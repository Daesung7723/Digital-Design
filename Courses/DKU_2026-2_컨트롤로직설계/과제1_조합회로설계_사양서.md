# 컨트롤로직 설계 — 과제 1 사양서

### 조합회로 설계 전 과정 · BCD → 7-세그먼트 디코더

> 답안은 [과제 1 양식](과제1_조합회로설계_양식.md)에 작성해 제출합니다.

## 2. 설계 대상

숫자를 표시하는 장치는 0부터 9까지의 값을 **7개 세그먼트의 점등 조합**으로 나타냅니다. 4비트 BCD(Binary Coded Decimal) 입력을 받아 각 세그먼트의 점등 여부를 결정하는 조합회로가 7-세그먼트 디코더입니다.

### 2.1 세그먼트 배치

```
     a
   ─────
  f│   │b
   │ g │
   ─────
  e│   │c
   │   │
   ─────
     d
```

### 2.2 입출력 정의

| 구분 | 신호 | 비트 | 의미 |
|------|------|:--:|------|
| 입력 | $B_3 B_2 B_1 B_0$ | 4 | BCD 코드 (0000\~1001 = 십진 0\~9) |
| 출력 | $a, b, c, d, e, f, g$ | 7 | 각 세그먼트의 점등 신호 |

- **출력 극성**: 공통 음극 방식으로 가정합니다 — 해당 세그먼트를 점등할 때 출력이 1입니다.
- **무관 조건**: 입력 1010\~1111(십진 10\~15)은 BCD로 정의되지 않은 값이므로 **무관 조건**(don't care)으로 처리할 수 있습니다.

---

## 3. 요구 사항

설계 절차 5단계를 순서대로 수행하고 각 단계의 결과를 모두 제출하십시오.

| Step | 수행 내용 | 산출물 |
|:--:|------|------|
| 1 | 사양 확인 — 0~9의 표시 형태 결정 | 표시 형태 정의 |
| 2 | 입출력 변수 정의 | 입출력 정의표 |
| 3 | 진리표 작성 (16행) | 진리표 |
| 4 | 세그먼트별 카르노맵 최소화 (7개) | 카르노맵 7장 + 최소식 7개 |
| 5 | 게이트 회로도 작성 | 회로도 |

### 3.1 무관 조건 활용 (필수)

- 4단계의 카르노맵 7장 모두에서 **무관 조건을 활용**하십시오.
- 추가로 **세그먼트 $g$ 한 개**만 무관 조건을 0으로 처리했을 때의 최소식을 별도로 구하고 두 결과를 비교하십시오.

| 비교 항목 | 무관 조건 활용 | 무관 조건 0 처리 |
|------|:--:|:--:|
| 최소식 | | |
| 게이트 수 | | |

> 무관 조건을 사용하는 이유가 이 비교에서 드러납니다. 나머지 6개 세그먼트는 무관 조건을 활용한 결과만 제출하면 됩니다.

### 3.2 수기 작성 범위

- 진리표·카르노맵·최소식·회로도를 **수기로 작성**한 뒤 사진 또는 스캔으로 첨부하십시오.
- 카르노맵에 묶음의 범위를 표시하십시오.

## 4. 구현·검증 (Logisim)

- 4단계에서 얻은 최소식을 Logisim Evolution으로 구현하십시오.
- 출력을 7-세그먼트 표시 부품에 연결하십시오.
- **검증 범위**: 입력 0000부터 1001까지 **10개 값 전부**의 표시 결과를 확인하고 캡처하십시오.

**캡처 시 유의 사항**

- 입력 핀과 출력 핀에 신호 이름을 표시할 것
- 회로 전체가 한 화면에서 판독되도록 캡처할 것
- 10개 값의 표시 결과는 한 장에 모으거나 나누어 제시할 것

## 7. 유의 사항

- **핵심은 과정입니다.** 정답 회로만 있고 유도 과정이 없으면 감점합니다. 과정이 타당하고 사소한 실수만 있으면 부분 인정합니다.
- 최소식은 사람마다 다를 수 있습니다. 묶음 방식에 따라 형태가 바뀌더라도 **진리표를 만족하고 더 간소화할 수 없으면** 정답으로 인정합니다.
- 기한을 넘겨 제출하면 감점합니다.
