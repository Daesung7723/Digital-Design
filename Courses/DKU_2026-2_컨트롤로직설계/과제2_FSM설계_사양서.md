## 2. 설계 대상

부품을 한 개씩 공급받아 검사하고, 불량품만 라인 밖으로 배출하는 생산 라인의 제어기를 설계합니다. 제어기는 각 단계에서 해당 설비를 동작시키는 제어 신호를 출력하고, 검사 판정에 따라 진행 경로를 결정합니다.

### 2.1 입출력 정의

| 구분 | 신호 | 의미 |
|------|------|------|
| 입력 | `START` | 시작 요청 — 1이면 새 부품의 공정 시작 |
| 입력 | `PASS` | 검사 판정 — 1이면 양품, 0이면 불량 |
| 출력 | `FEED` | 부품 공급기 동작 |
| 출력 | `TEST` | 검사 장치 동작 |
| 출력 | `REJECT` | 불량 배출기 동작 |

### 2.2 기능 정의

1. **초기 대기** — 전원을 인가하면 이 단계에서 대기합니다. 출력은 없습니다. `START`가 1이면 투입 단계로 진행하고, 0이면 대기를 유지합니다.
2. **투입** — `FEED`를 1로 출력해 부품을 공급합니다. 다음 클록에 검사 단계로 진행합니다.
3. **검사** — `TEST`를 1로 출력해 검사를 수행합니다. 다음 클록에 판정 `PASS`에 따라 진행합니다.
   - `PASS`가 1이면 양품입니다. 양품은 라인을 따라 그대로 이송되므로 별도의 동작 없이 **사이클 대기** 단계로 진행합니다.
   - `PASS`가 0이면 **불량 배출** 단계로 진행합니다.
4. **불량 배출** — `REJECT`를 1로 출력해 불량품을 라인 밖으로 배출합니다. 다음 클록에 사이클 대기 단계로 진행합니다.
5. **사이클 대기** — 한 부품의 공정이 완료된 상태입니다. 출력은 없습니다. `START`가 1이면 다시 투입 단계로 진행하고, 0이면 대기를 유지합니다.

### 2.3 타이밍 규약

- **동작 단계**(투입·검사·불량 배출)는 **클록 1주기** 동안 유지되며, 그 주기 동안 해당 출력이 1입니다.
- **대기 단계**(초기 대기·사이클 대기)는 `START`가 1이 될 때까지 유지되며, 출력은 없습니다.
- 단계 완료 신호는 따로 두지 않습니다. 설비의 동작이 클록 1주기 안에 완료된다고 가정합니다.

## 3. 요구 사항

설계 7단계를 순서대로 수행하고, 각 단계의 결과를 모두 제출하십시오.

| Step | 수행 내용 | 산출물 |
|:--:|------|------|
| 1 | 기능 정의에서 상태를 도출해 상태도 작성 | 상태도(축소 전) |
| 2 | **상태 축소** — 등가 상태 판별·병합 | 등가 판정 근거 + 축소 상태도 |
| 3 | **상태 할당** — 이진·Gray·원핫 중 선택 | 할당표 + 선택 근거 |
| 4 | 상태표 작성 + **여기표** 적용 | 상태표(플립플롭 입력 포함) |
| 5 | 플립플롭 입력 방정식·출력 방정식 도출 | 카르노맵 + 방정식 |
| 6 | 논리 회로도 작성 | 회로도 |
| 7 | Logisim 구현·검증 | 회로 + 시뮬레이션 캡처 |

### 3.1 지정 조건

| 항목 | 조건 |
|------|------|
| 회로 유형 | **Moore로 설계하십시오** — 출력은 현재 상태만으로 결정됩니다. 제어 신호가 상태에서 나오는 구조가 제어유닛의 기본 형태입니다(13장). |
| 플립플롭 | **D·JK·T 중 선택** — 선택 근거를 1~2문장으로 서술하십시오. |
| 상태 할당 | **이진·Gray·원핫 중 선택** — 선택 근거를 1~2문장으로 서술하십시오. |

### 3.2 상태 축소 (필수)

- 1단계에서 도출한 상태도에 **등가 상태가 있는지 판별**하고, 있으면 병합한 뒤 축소 상태도를 제시하십시오.
- 등가로 판정한 근거를 **출력과 다음 상태 양쪽**에 대해 밝히십시오.
- 등가가 없다고 판단했다면 그 근거를 서술하십시오.

> 등가 판정은 연쇄됩니다 — 한 쌍을 병합하면 다른 쌍의 판정이 달라질 수 있으므로 반복해 비교하십시오.

### 3.3 수기 작성 범위

- 상태도·상태표·여기표·카르노맵·방정식·회로도는 **수기로 작성**한 뒤 사진 또는 스캔으로 첨부하십시오.
- 상태도에는 초기 상태를 표시하고, 전이 조건을 화살표 위에 기재하십시오.

## 4. 구현·검증 (Logisim)

- 5단계에서 얻은 방정식을 Logisim Evolution으로 구현하십시오.
- 클록·리셋 입력을 두고, 상태 값과 출력 3종을 관찰할 수 있도록 배치하십시오.

**검증 시퀀스** — 초기 대기에서 시작해 아래 두 경로가 **모두 관찰되는** 입력 시퀀스를 직접 정하고 결과를 캡처하십시오.

| # | 경로 | 단계 흐름 |
|:--:|------|------|
| 1 | 양품 경로 (`PASS=1`) | 투입 → 검사 → 사이클 대기 |
| 2 | 불량 경로 (`PASS=0`) | 투입 → 검사 → 불량 배출 → 사이클 대기 |

**캡처 시 유의 사항**

- 입력 핀과 출력 핀에 신호 이름을 표시할 것
- 회로 전체가 한 화면에서 판독되도록 캡처할 것
- 클록별 상태·출력 변화를 예상 동작표와 대조할 것

## 7. 유의 사항

- **핵심은 과정입니다.** 정답 회로만 있고 유도 과정이 없으면 감점합니다. 과정이 타당하고 사소한 실수만 있으면 부분 인정합니다.
- 플립플롭 종류와 상태 할당을 무엇으로 정하든 감점하지 않습니다. 다만 **선택 근거가 없으면** 감점합니다.
- 기한을 넘겨 제출하면 감점합니다.
