### 3. 상태 테이블 및 JK 여기표

현재 상태, 입력, 다음 상태, 출력, 각 플립플롭의 J·K 입력값을 작성하시오.

#### JK 여기표 참조

| 현재 Q | 다음 Q | J | K |
|:------:|:------:|:---:|:---:|
| 0 | 0 | 0 | X |
| 0 | 1 | 1 | X |
| 1 | 0 | X | 1 |
| 1 | 1 | X | 0 |

#### 상태 테이블

| 현재 상태 | 입력 | 다음 상태 | 출력 | J₂ | K₂ | J₁ | K₁ | J₀ | K₀ |
|:---------:|:----:|:---------:|:----:|:--:|:--:|:--:|:--:|:--:|:--:|
| | | | | | | | | | |
| | | | | | | | | | |
| | | | | | | | | | |
| | | | | | | | | | |

*플립플롭이 2개인 경우 J₂·K₂ 열을 삭제하고 사용하시오. (2개: 최대 4상태 / 3개: 최대 8상태)*
