# 08장 보충학습
- 대상: 프로세스 개념이 처음인 초보 학습자
- 목적: 프로세스와 잡의 개념을 이해하고 `ps`, `kill`, `jobs`, `fg`, `bg`를 사용할 수 있도록 한다.

## 1. 보충학습 목표
- 프로세스와 PID의 개념을 이해한다.
- `ps`로 실행 중인 프로세스를 확인할 수 있다.
- `kill`로 프로세스를 종료할 수 있다.
- 포그라운드/백그라운드 작업을 전환할 수 있다.

## 2. 본문과 연결되는 내용
- 8장 본문은 프로세스 개념, `ps`, `kill`, `nice`, `top`, 잡 제어, 시그널을 다룬다.
- `ps`, `pgrep`, `kill`, `pkill`, `nice`, `top`, `jobs`, `fg`, `bg`, `nohup`이 포함되어 있다.

## 3. 핵심 정리
- 프로세스는 현재 실행 중인 프로그램이다.
- 모든 프로세스는 고유한 번호(PID)를 가진다.
- 포그라운드: 현재 터미널을 점유하며 실행 중인 작업.
- 백그라운드: 터미널을 점유하지 않고 뒤에서 실행 중인 작업.
- `&`를 명령 뒤에 붙이면 백그라운드로 실행된다.

## 4. 보충학습 내용 1: ps로 프로세스 확인
- 현재 터미널의 프로세스
  ```bash
  ps
  ```
- 전체 프로세스 보기 (자주 쓰는 방식)
  ```bash
  ps -ef
  ps -ef | grep bash
  ```
- BSD 스타일 (CPU/메모리 포함)
  ```bash
  ps aux
  ps aux | grep python3
  ```
- PID로 특정 프로세스 검색
  ```bash
  pgrep bash
  pgrep -l bash
  ```

## 5. 보충학습 내용 2: kill로 프로세스 종료
- PID로 종료
  ```bash
  kill 1234
  ```
- 강제 종료 (-9 시그널)
  ```bash
  kill -9 1234
  ```
- 프로세스 이름으로 종료
  ```bash
  pkill sleep
  ```
- 주요 시그널

  | 번호 | 이름 | 의미 |
  |---|---|---|
  | 2 | SIGINT | 인터럽트 (`Ctrl + C`와 동일) |
  | 9 | SIGKILL | 강제 종료 (무조건 종료) |
  | 15 | SIGTERM | 정상 종료 요청 (기본값) |

## 6. 보충학습 내용 3: 잡 제어 (포그라운드/백그라운드)
- 백그라운드로 실행
  ```bash
  sleep 100 &
  ```
- 현재 잡 목록 보기
  ```bash
  jobs
  ```
- 포그라운드로 전환
  ```bash
  fg
  fg %1
  ```
- 포그라운드 작업을 백그라운드로 전환
  - 실행 중 `Ctrl + Z` → 일시 정지
  - `bg` 입력 → 백그라운드로 재시작
- 포그라운드 작업 강제 종료
  - `Ctrl + C`

## 7. 보충학습 내용 4: top으로 실시간 모니터링
- 실시간 프로세스 확인
  ```bash
  top
  ```
- `top` 화면에서 자주 쓰는 키
  - 종료: `q`
  - CPU 사용량 정렬: `P`
  - 메모리 사용량 정렬: `M`
  - 프로세스 종료: `k` → PID 입력

## 8. 추가 실습
- 실습 1: 프로세스 확인
  ```bash
  ps
  ps -ef | grep bash
  ps aux | head
  ```
- 실습 2: 백그라운드 실행
  ```bash
  sleep 100 &
  sleep 200 &
  jobs
  ```
- 실습 3: 포그라운드 전환 및 종료
  ```bash
  fg %1
  Ctrl + C
  jobs
  ```
- 실습 4: Ctrl+Z 후 백그라운드 전환
  ```bash
  sleep 300
  # Ctrl + Z
  bg
  jobs
  ```
- 실습 5: kill 사용
  ```bash
  sleep 500 &
  pgrep sleep
  kill PID값
  jobs
  ```
- 실습 6: top 확인
  ```bash
  top
  ```

## 9. 체크리스트
- 프로세스와 PID의 개념을 설명할 수 있다.
- `ps -ef | grep 명령어`로 특정 프로세스를 찾을 수 있다.
- `&`로 백그라운드 실행을 할 수 있다.
- `jobs`, `fg`, `bg`를 사용할 수 있다.
- `kill`로 프로세스를 종료할 수 있다.

## 10. 주의사항
- `kill -9`는 강제 종료이므로 데이터 손실 가능성이 있다. 먼저 `kill 15`(기본값)를 시도한다.
- `pkill`은 같은 이름의 프로세스를 모두 종료할 수 있으므로 주의한다.
- `top`은 `q`를 눌러 종료한다.

## 11. 8장 보충학습 완료 기준
- 프로세스 확인 및 종료 가능 상태.
- 포그라운드/백그라운드 전환 가능 상태.
- 9장 사용자 관리 실습 진행 가능 상태.
