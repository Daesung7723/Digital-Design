# 10장 보충학습
- 대상: 파일 압축과 디스크 관리 개념이 처음인 초보 학습자
- 목적: tar, gzip, zip을 사용해 파일을 압축/해제하고, df/du로 디스크를 확인할 수 있도록 한다.

## 1. 보충학습 목표
- `df`, `du`로 디스크 사용량을 확인할 수 있다.
- `tar`로 파일을 묶고 풀 수 있다.
- `gzip`, `bzip2`, `zip`으로 파일을 압축하고 해제할 수 있다.

## 2. 본문과 연결되는 내용
- 10장 본문은 디스크 구조, `df`, `du`, `tar`, 압축(`gzip`, `bzip2`, `zip`, `compress`), `dd`를 다룬다.
- 백업과 복원의 기본이 되는 압축 명령 사용법이 포함되어 있다.

## 3. 핵심 정리
- `tar`는 여러 파일을 하나로 묶는 도구다 (압축은 별도 옵션 필요).
- `gzip`은 리눅스에서 가장 널리 쓰는 압축 방식이다.
- `zip`은 윈도우와 호환되어 파일 교환에 유용하다.
- `df`는 디스크 전체 사용량, `du`는 특정 디렉터리 크기를 확인한다.

## 4. 보충학습 내용 1: 디스크 사용량 확인
- 전체 디스크 사용량
  ```bash
  df -h
  ```
- 파일 시스템 종류 포함
  ```bash
  df -Th
  ```
- 특정 디렉터리 크기
  ```bash
  du -sh ~/study
  du -sh /etc
  ```
- 하위 디렉터리별 크기
  ```bash
  du -h ~/study
  ```

## 5. 보충학습 내용 2: tar 사용법
- tar 주요 옵션

  | 옵션 | 의미 |
  |---|---|
  | `c` | 묶기 (create) |
  | `x` | 풀기 (extract) |
  | `t` | 목록 보기 |
  | `v` | 과정 출력 (verbose) |
  | `f` | 파일 이름 지정 |
  | `z` | gzip 압축 함께 |
  | `j` | bzip2 압축 함께 |

- 파일 묶기
  ```bash
  tar cvf ch03.tar ~/study/ch03
  ```
- 목록 확인
  ```bash
  tar tvf ch03.tar
  ```
- 풀기
  ```bash
  tar xvf ch03.tar
  ```
- gzip으로 묶고 압축 (한 번에)
  ```bash
  tar cvfz ch03.tar.gz ~/study/ch03
  ```
- 압축 해제 (한 번에)
  ```bash
  tar xvfz ch03.tar.gz
  ```

## 6. 보충학습 내용 3: gzip 사용법
- 파일 압축 (.gz 생성, 원본 삭제)
  ```bash
  gzip ch03.tar
  ```
- 압축 해제
  ```bash
  gunzip ch03.tar.gz
  ```
- 압축 정보 확인
  ```bash
  gzip -l ch03.tar.gz
  ```
- 내용 확인 (압축 해제 없이)
  ```bash
  zcat ch03.tar.gz | tar tv
  ```

## 7. 보충학습 내용 4: zip/unzip 사용법
- 압축
  ```bash
  zip ch03.zip ~/study/ch03
  zip -r ch03.zip ~/study/ch03    # 디렉터리 포함
  ```
- 압축 해제
  ```bash
  unzip ch03.zip
  unzip ch03.zip -d /tmp/unzip_test
  ```

## 8. 추가 실습
- 실습 1: 디스크 확인
  ```bash
  df -h
  du -sh ~/study
  ```
- 실습 2: tar로 묶기/풀기
  ```bash
  mkdir -p ~/study/ch10
  cd ~/study/ch10
  tar cvf ch03.tar ~/study/ch03
  tar tvf ch03.tar
  mkdir restore_test
  tar xvf ch03.tar -C restore_test
  ls restore_test
  ```
- 실습 3: tar + gzip
  ```bash
  tar cvfz ch03.tar.gz ~/study/ch03
  ls -lh ch03.tar.gz
  tar xvfz ch03.tar.gz -C /tmp
  ```
- 실습 4: zip
  ```bash
  zip -r ch03.zip ~/study/ch03
  unzip ch03.zip -d /tmp/zip_test
  ls /tmp/zip_test
  ```

## 9. 체크리스트
- `df -h`와 `du -sh`로 디스크 사용량을 확인할 수 있다.
- `tar cvf`, `tar tvf`, `tar xvf`를 사용할 수 있다.
- `tar cvfz`로 묶기와 압축을 동시에 할 수 있다.
- `zip`, `unzip`을 사용할 수 있다.

## 10. 주의사항
- `tar cvf` 실행 전 저장 위치와 파일 이름을 확인한다.
- `gzip`은 원본 파일을 삭제하므로 주의한다.
- 압축 해제 전 `-C` 옵션으로 위치를 지정하면 정리가 쉽다.
