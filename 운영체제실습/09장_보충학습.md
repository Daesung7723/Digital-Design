# 09장 보충학습
- 대상: 사용자 계정 관리 개념이 처음인 초보 학습자
- 목적: 사용자 정보 파일의 구조를 이해하고, su/sudo 사용법을 익히도록 한다.

## 1. 보충학습 목표
- 사용자 관련 시스템 파일(`/etc/passwd`, `/etc/shadow`)의 구조를 이해한다.
- `who`, `w`, `id`, `groups` 명령으로 사용자 정보를 확인할 수 있다.
- `su`와 `sudo`의 차이를 이해하고 사용할 수 있다.
- UID와 EUID의 차이를 간단히 이해한다.

## 2. 본문과 연결되는 내용
- 9장 본문은 사용자 정보 파일, 로그인/로그아웃 확인, `su`, `sudo`, UID/EUID를 다룬다.
- `/etc/passwd`, `/etc/shadow`, `/etc/group`, `who`, `w`, `last`, `su`, `sudo`가 포함되어 있다.

## 3. 핵심 정리
- root는 시스템 관리자 계정으로 모든 권한을 가진다.
- 일반 사용자는 `sudo`를 이용해 필요한 작업만 관리자 권한으로 실행한다.
- root 계정으로 항상 작업하는 것은 보안상 위험하다.
- `su`는 계정 전체를 전환, `sudo`는 명령 단위로 권한을 빌린다.

## 4. 보충학습 내용 1: 사용자 정보 파일 구조
- `/etc/passwd` 파일 확인
  ```bash
  cat /etc/passwd | grep user1
  ```
- 필드 구조 (콜론으로 구분, 총 7개 필드)
  ```text
  user1 : x : 1000 : 1000 : user1,,, : /home/user1 : /bin/bash
  로그인ID : 패스워드 : UID : GID : 설명 : 홈디렉터리 : 셸
  ```
- `/etc/shadow` 파일 (비밀번호 암호화 저장, root만 읽기 가능)
  ```bash
  sudo cat /etc/shadow | grep user1
  ```

## 5. 보충학습 내용 2: 사용자 확인 명령
- 현재 로그인한 사용자 목록
  ```bash
  who
  ```
- 자세한 사용자 정보 (현재 작업 포함)
  ```bash
  w
  ```
- 최근 로그인 기록
  ```bash
  last
  ```
- 현재 사용자 ID 확인
  ```bash
  id
  whoami
  groups
  ```

## 6. 보충학습 내용 3: su와 sudo
- `su` - 계정 전환
  ```bash
  su root           # root로 전환 (환경변수 유지)
  su - root         # root로 완전 전환 (환경변수 초기화)
  exit              # 이전 계정으로 돌아가기
  ```

- `sudo` - 명령 단위 권한 실행
  ```bash
  sudo apt update
  sudo useradd user3
  sudo cat /etc/shadow
  ```

- `su`와 `sudo` 비교

  | 항목 | su | sudo |
  |---|---|---|
  | 방식 | 계정 전체 전환 | 명령 단위로 권한 실행 |
  | 비밀번호 | root 비밀번호 필요 | 자신의 비밀번호 입력 |
  | 권장 여부 | 가능하면 사용 자제 | 권장 방식 |

## 7. 보충학습 내용 4: UID와 EUID
- UID: 실제 사용자 ID (로그인한 계정).
- EUID: 유효 사용자 ID (현재 실행 중인 권한).
- 확인 방법
  ```bash
  id
  ```
- 일반 상황에서는 UID와 EUID가 같다.
- `sudo` 실행 시 EUID가 0(root)으로 바뀐다.

## 8. 추가 실습
- 실습 1: 현재 사용자 확인
  ```bash
  whoami
  id
  groups
  who
  ```
- 실습 2: 사용자 파일 확인
  ```bash
  cat /etc/passwd | grep user1
  cat /etc/group | grep user1
  ```
- 실습 3: last로 로그인 기록 확인
  ```bash
  last
  last | grep user1
  ```
- 실습 4: sudo 사용
  ```bash
  sudo apt update
  sudo cat /etc/shadow | head -3
  ```
- 실습 5: su 사용 (연습 후 반드시 exit)
  ```bash
  su - user1
  whoami
  exit
  ```

## 9. 체크리스트
- `/etc/passwd` 파일의 필드 구조를 설명할 수 있다.
- `who`, `w`, `id`, `groups`를 실행할 수 있다.
- `su`와 `sudo`의 차이를 설명할 수 있다.
- `sudo`로 관리자 명령을 실행할 수 있다.

## 10. 주의사항
- `su root`로 전환 후 작업이 끝나면 반드시 `exit`으로 돌아온다.
- root 계정에서 실수로 파일을 삭제하면 복구가 어렵다.
- sudo 권한은 필요한 명령에만 최소한으로 사용한다.
