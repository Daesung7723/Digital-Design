# 13장 보충학습
- 대상: 시스템 관리 개념이 처음인 초보 학습자
- 목적: 패키지 설치/제거, 서비스 관리, 네트워크 확인, FTP/웹 서버 기본 설정을 할 수 있도록 한다.

## 1. 보충학습 목표
- 시스템 부팅 과정을 간단히 이해한다.
- `apt`로 패키지를 설치하고 제거할 수 있다.
- `systemctl`로 서비스를 시작/중지/확인할 수 있다.
- `nmcli`로 네트워크 상태를 확인할 수 있다.
- FTP 서버와 Apache 웹 서버를 설치하고 기본 동작을 확인할 수 있다.

## 2. 본문과 연결되는 내용
- 13장 본문은 부팅, 사용자 계정 추가, apt 패키지 관리, systemd 서비스 관리, 네트워크 관리, FTP, 웹 서버를 다룬다.
- `useradd`, `apt`, `systemctl`, `nmcli`, `vsftpd`, `apache2`가 포함되어 있다.

## 3. 핵심 정리
- Ubuntu의 기본 패키지 관리 도구는 `apt`이다.
- `systemctl`은 systemd 기반 서비스를 관리하는 명령이다.
- 서비스를 설치한 후 `start` → `status` 순서로 확인하는 습관을 들인다.
- 네트워크 설정은 `nmcli` 또는 GUI로 할 수 있다.

## 4. 보충학습 내용 1: 시스템 종료 및 재부팅
- 즉시 종료
  ```bash
  sudo shutdown -h now
  ```
- 2분 후 종료 (사용자에게 메시지 전달)
  ```bash
  sudo shutdown -h 2
  ```
- 재부팅
  ```bash
  sudo reboot
  sudo shutdown -r 3
  ```
- 종료 취소
  ```bash
  sudo shutdown -c
  ```

## 5. 보충학습 내용 2: 사용자 계정 추가
- 사용자 추가
  ```bash
  sudo useradd -m han01
  ```
- 비밀번호 설정
  ```bash
  sudo passwd han01
  ```
- 사용자 확인
  ```bash
  cat /etc/passwd | grep han01
  ```
- 사용자 삭제
  ```bash
  sudo userdel -r han01
  ```

## 6. 보충학습 내용 3: apt 패키지 관리
- 패키지 목록 갱신
  ```bash
  sudo apt update
  ```
- 패키지 설치
  ```bash
  sudo apt install 패키지명 -y
  ```
- 패키지 제거
  ```bash
  sudo apt remove 패키지명
  ```
- 패키지 검색
  ```bash
  apt search gimp
  ```
- 설치된 패키지 목록
  ```bash
  dpkg -l | grep 패키지명
  ```

## 7. 보충학습 내용 4: systemctl 서비스 관리
- 서비스 관련 주요 명령

  | 명령 | 의미 |
  |---|---|
  | `systemctl start 서비스` | 서비스 시작 |
  | `systemctl stop 서비스` | 서비스 중지 |
  | `systemctl restart 서비스` | 서비스 재시작 |
  | `systemctl status 서비스` | 서비스 상태 확인 |
  | `systemctl enable 서비스` | 부팅 시 자동 시작 등록 |
  | `systemctl disable 서비스` | 자동 시작 해제 |
  | `systemctl is-active 서비스` | 활성 여부 확인 |

- 예시
  ```bash
  systemctl status ssh
  sudo systemctl start ssh
  sudo systemctl enable ssh
  ```

## 8. 보충학습 내용 5: 네트워크 확인 (nmcli)
- 네트워크 장치 상태 확인
  ```bash
  nmcli dev status
  ```
- 네트워크 상세 정보 확인
  ```bash
  nmcli dev show
  ```
- IP 주소 확인
  ```bash
  hostname -I
  ip a
  ```

## 9. 보충학습 내용 6: FTP 서버 설치 및 사용
- vsftpd 설치
  ```bash
  sudo apt install vsftpd -y
  sudo systemctl start vsftpd
  sudo systemctl status vsftpd
  ```
- FTP 접속 (같은 서버에서)
  ```bash
  ftp localhost
  ```
- FTP 주요 명령

  | 명령 | 의미 |
  |---|---|
  | `ls` | 원격 파일 목록 |
  | `pwd` | 원격 현재 위치 |
  | `get 파일명` | 파일 내려받기 |
  | `put 파일명` | 파일 올리기 |
  | `bye` | 접속 종료 |

## 10. 보충학습 내용 7: Apache 웹 서버 설치 및 확인
- apache2 설치
  ```bash
  sudo apt install apache2 -y
  sudo systemctl start apache2
  sudo systemctl status apache2
  ```
- 기본 웹 페이지 확인
  - 브라우저에서 `http://localhost` 접속
  - Ubuntu Apache2 기본 페이지가 보이면 정상

- 기본 HTML 파일 수정
  ```bash
  sudo nano /var/www/html/index.html
  ```
  - 내용 수정 후 저장
  - 브라우저 새로고침으로 확인

## 12. 체크리스트
- `apt`로 패키지를 설치하고 제거할 수 있다.
- `systemctl`로 서비스 상태를 확인하고 시작/중지할 수 있다.
- `nmcli dev status`와 `hostname -I`로 네트워크 상태를 확인할 수 있다.
- FTP 서버를 설치하고 기본 접속을 할 수 있다.
- Apache 웹 서버를 설치하고 브라우저로 확인할 수 있다.

## 13. 주의사항
- `apt install` 전 반드시 `apt update`를 먼저 실행한다.
- 서비스 시작/중지는 반드시 `sudo`를 사용한다.
- FTP는 비밀번호가 평문 전송되므로 실제 환경에서는 SFTP를 사용한다.
- 웹 서버 파일 수정 시 반드시 `sudo nano`를 사용한다.
