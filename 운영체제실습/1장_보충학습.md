# 01장 보충학습

- 대상: Ubuntu 24.04 LTS를 VMware Workstation 환경에 설치한 초보 학습자
- 목적: 1장 본문 학습 후, 이후 장 실습에 필요한 기본 환경을 완성하기 위함

## 1. 보충학습 목표

- Ubuntu 24.04 가상머신을 설치한 뒤 실습 가능한 상태까지 환경을 완성한다.
- 터미널 실행, 기본 패키지 설치, VMware 연동, 공유 폴더 연결까지 마무리한다.
- 2장 이후 실습에 필요한 최소 도구를 미리 준비한다.

## 2. 본문과 연결되는 내용

- 1장 본문은 운영체제 개요, 유닉스와 리눅스, 배포판, VMware 기반 Ubuntu 설치를 다룬다.
- 1장 학습목표에는 가상머신 이해와 Ubuntu 설치가 포함되어 있다.
- 보충학습은 설치 완료 이후 "실습 준비 마무리"에 초점을 둔다.

## 3. 핵심 정리

- 운영체제는 하드웨어와 응용 프로그램 사이에서 자원을 관리하는 소프트웨어이다.
- 리눅스 학습에서는 설치 자체보다 "명령을 실행할 수 있는 환경"을 만드는 것이 더 중요하다.
- VMware 실습에서는 복사/붙여넣기, 공유 폴더, 편집기 설치가 학습 편의성에 큰 영향을 준다.
- 설치 시 기본 계정: 사용자 이름 `user1`, 컴퓨터 이름 `hanbit` (교재 기준)

## 4. 실습 전 확인

- 터미널 실행 방법
  
  - `Ctrl + Alt + T`
  - 또는 앱 표시 → 터미널 실행
- 현재 환경 확인
  
  ```bash
  whoami
  hostname
  pwd
  ip a
  ```
  
- 확인 내용
  
  - `whoami`: 현재 로그인한 사용자 확인 → `user1` 출력되면 정상
  - `hostname`: 현재 컴퓨터 이름 확인 → `hanbit` 출력되면 정상
  - `pwd`: 현재 위치 확인 → `/home/user1` 출력되면 정상
  - `ip a`: 네트워크 상태 확인 → IP 주소가 표시되면 정상

## 5. 보충학습 내용 1: VMware Tools 설치

- 목적
  
  - 윈도우와 우분투 간 복사/붙여넣기 지원
  - 화면 크기 자동 조정 및 연동 기능 개선
  - VMware 실습 편의성 향상
- 설치 명령
  
  ```bash
  sudo apt update
  sudo apt install open-vm-tools-desktop -y
  sudo reboot
  ```
  
- 명령 설명
  
  - `sudo apt update`: 패키지 목록을 최신 상태로 갱신
  - `open-vm-tools-desktop`: VMware 환경에서 게스트 운영체제 연동 기능 제공
  - `sudo reboot`: 시스템 재시작
- 확인 방법
  
  - 재부팅 후 윈도우에서 텍스트를 복사한다.
  - 우분투 터미널 또는 편집기에 붙여넣기 해본다.
  - 붙여넣기가 되면 정상 동작으로 본다.

## 6. 보충학습 내용 2: 텍스트 에디터(nano) 및 기본 도구 설치

- 목적
  
  - 초보자가 쉬운 편집기인 nano를 사용할 수 있게 준비
  - 이후 장에서 필요한 기본 개발 도구를 함께 설치
- 설치 명령
  
  ```bash
  sudo apt install build-essential git nano -y
  ```
  
- 포함 패키지
  
  - `nano`: 쉬운 텍스트 편집기 (본 강의에서 vi 대신 사용)
  - `git`: 소스 코드 관리 도구
  - `build-essential`: 기본 컴파일 도구 모음
- 본문 연결
  
  - 4장에서는 nano 편집기를 본격적으로 다룬다.
  - 12장에서는 컴파일과 개발 환경을 다룬다.
  - 따라서 1장에서 미리 설치해 두면 이후 실습이 편해진다.

## 7. 보충학습 내용 3: nano 사용 맛보기

- 실행 명령
  
  ```bash
  nano test.txt
  ```
  
- 연습 방법
  
  - 파일이 열리면 한 줄 입력
  - 저장: `Ctrl + O`
  - 확인: `Enter`
  - 종료: `Ctrl + X`
- 저장 확인
  
  ```bash
  cat test.txt
  ```
  
- 기대 효과
  
  - 파일 생성, 저장, 종료 경험을 먼저 익힐 수 있다.

## 8. 보충학습 내용 4: 공유 폴더 설정

- 목적
  - 윈도우와 우분투 간 파일 공유
  - 실습 파일, 예제 코드, 과제 파일 이동을 쉽게 처리

### 8-1. VMware 설정

- 메뉴 이동: `Settings > Options > Shared Folders`
- `Always enabled` 체크
- 윈도우에서 공유할 폴더 지정

### 8-2. 우분투 내 마운트 폴더 생성

```bash
sudo mkdir -p /mnt/hgfs
```

### 8-3. 수동 연결

- `/mnt/hgfs` 폴더가 비어 있거나 공유 폴더가 보이지 않을 때 실행
  
  ```bash
  sudo vmhgfs-fuse .host:/ /mnt/hgfs -o allow_other
  ```
  

### 8-4. 연결 확인

```bash
ls /mnt/hgfs
```

### 8-5. 자동 마운트 설정

- 설정 파일 열기
  
  ```bash
  sudo nano /etc/fstab
  ```
  
- 파일 맨 아래에 아래 내용 추가
  
  ```
  .host:/ /mnt/hgfs fuse.vmhgfs-fuse allow_other,defaults 0 0
  ```
  

### 8-6. 재부팅 및 재확인

```bash
sudo reboot
ls /mnt/hgfs
```

## 10. 체크리스트

- Ubuntu 24.04에 `user1` 계정으로 로그인할 수 있다.
- 터미널을 열 수 있다.
- `sudo apt update`를 실행할 수 있다.
- `nano`로 파일을 만들고 저장할 수 있다.
- 윈도우와 우분투 사이의 복사/붙여넣기가 가능하다.
- `/mnt/hgfs`에서 공유 폴더를 확인할 수 있다.

## 11. 주의사항

- 명령어는 반드시 한 줄 전체를 정확히 입력한다.
- `sudo` 실행 후 비밀번호 입력 시 화면에 글자가 보이지 않아도 정상이다.
- `/etc/fstab` 수정 시 오타가 있으면 자동 마운트가 실패할 수 있으므로 한 글자씩 확인한다.
- 재부팅 후 문제가 생기면 `/mnt/hgfs` 존재 여부와 VMware 공유 폴더 설정을 다시 확인한다.
