# 02장 보충학습

- 대상: Ubuntu 24.04 LTS를 처음 사용하는 초보 학습자
- 목적: GUI와 터미널의 차이를 이해하고, 터미널에서 기본 명령을 사용할 수 있도록 한다.

## 1. 보충학습 목표

- Ubuntu 데스크톱 환경의 기본 구성 요소를 이해한다.
- 터미널을 열고 종료할 수 있다.
- 프롬프트의 의미를 이해하고 간단한 명령을 입력할 수 있다.
- `man` 명령으로 도움말을 확인할 수 있다.

## 2. 본문과 연결되는 내용

- 2장 본문은 데스크톱 환경 소개, 데스크톱 사용, 리눅스 명령 사용으로 구성되어 있다.
- GNOME은 Ubuntu 24.04의 기본 데스크톱 환경(GNOME 46)으로 제시되어 있다.
- 터미널, 프롬프트, 기본 명령, `man` 명령 사용이 포함되어 있다.

## 3. 핵심 정리

- GUI는 마우스로 사용하는 화면 환경이다.
- CLI는 터미널에서 명령어를 입력하는 방식이다.
- Ubuntu 24.04 기본 데스크톱은 GNOME 46이다.
- 리눅스 학습에서는 GUI보다 터미널 사용 능력이 더 중요하다.

## 4. 꼭 알아둘 내용: 프롬프트 읽는 법

- 터미널 실행
  
  - `Ctrl + Alt + T`
- 프롬프트 예시
  
  ```
  user1@hanbit:~$
  ```
  
- 프롬프트 의미
  
  - `user1`: 사용자 이름
  - `hanbit`: 컴퓨터 이름
  - `~`: 현재 위치가 홈 디렉터리임을 뜻함
  - `$`: 일반 사용자 (관리자는 `#`)
- 터미널 종료 방법
  
  - `exit` 입력
  - 또는 `Ctrl + D`

## 5. 보충학습 내용 1: 명령어 구조 이해

- 기본 형식
  
  ```
  명령어  옵션  대상
  ```
  
- 예시
  
  ```bash
  ls
  ls -a
  ls /tmp
  ls -a /tmp
  ```
  
- 설명
  
  - `ls`: 현재 위치의 파일 목록 보기
  - `-a`: 숨김 파일까지 보기
  - `/tmp`: 특정 디렉터리 지정

## 6. 보충학습 내용 2: 자주 쓰는 기초 명령

- 날짜 확인
  
  ```bash
  date
  ```
  
- 화면 정리
  
  ```bash
  clear
  ```
  
- 현재 사용자 확인
  
  ```bash
  whoami
  ```
  
- 현재 위치 확인
  
  ```bash
  pwd
  ```
  
- 비밀번호 변경
  
  ```bash
  passwd
  ```
  

## 7. 보충학습 내용 3: 도움말 보기

- 기본 도움말
  
  ```bash
  man ls
  man pwd
  ```
  
- `man` 화면에서 자주 쓰는 키
  
  - 아래로 이동: `Enter` 또는 방향키
  - 페이지 이동: `Space`
  - 검색: `/문자열`
  - 종료: `q`
- 참고
  
  - `man` 화면이 멈춘 것처럼 보여도 정상이다.
  - 빠져나오려면 반드시 `q`를 누른다.

## 8. 보충학습 내용 4: SSH 접속 준비 (원격 접속용)

- 목적
  
  - 윈도우(PuTTY 등)에서 우분투에 원격 접속하기 위해 SSH 서비스를 설치한다.
- 설치 명령 (교재 기준)
  
  ```bash
  sudo apt update
  sudo apt install ssh -y
  ```
  
- 서비스 상태 확인
  
  ```bash
  systemctl status ssh
  ```
  
- IP 주소 확인
  
  ```bash
  hostname -I
  ```
  
- 참고
  
  - 접속이 안 될 경우 IP 주소와 SSH 서비스 상태를 먼저 확인한다.

## 10. 체크리스트

- 터미널을 열 수 있다.
- 프롬프트의 각 항목(`user1`, `hanbit`, `~`, `$`)의 의미를 설명할 수 있다.
- `ls`, `pwd`, `date`, `clear`를 실행할 수 있다.
- `man` 명령으로 도움말을 보고 `q`로 종료할 수 있다.
- `hostname -I`로 IP 주소를 확인할 수 있다.

## 11. 주의사항

- 명령어는 대소문자를 구분한다. (`ls`와 `LS`는 다르다)
- `man` 화면에서 나오지 못하면 `q`를 누른다.
- SSH 설치 후 접속이 안 되면 IP 주소와 서비스 상태를 먼저 확인한다.

- 3장 파일/디렉터리 실습 진행 가능 상태
