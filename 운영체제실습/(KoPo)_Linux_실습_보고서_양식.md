## Mission 8 — Python 스크립트 실행

**목표**: 제공된 `analyze_scores.py`를 실행하여 `filtered.txt`의 성적 통계를 출력한다.  
**전제**: M5 완료 (`results/filtered.txt` 존재)

> `analyze_scores.py`는 GitHub에서 다운로드하여 `scripts/` 폴더에 저장하시오.

**제공 코드** (`analyze_scores.py`)

```python
# analyze_scores.py
# M5에서 생성된 filtered.txt를 읽어 성적 통계를 출력합니다.

import os

filepath = os.path.expanduser('~/score_project/results/filtered.txt')

names = []
scores = []

with open(filepath, 'r') as f:
    for line in f:
        parts = line.strip().split()
        if len(parts) == 2:
            names.append(parts[0])
            scores.append(int(parts[1]))

print("=== 성적 분석 결과 ===")
print(f"학생 수 : {len(scores)}명")
print(f"최고점  : {max(scores)}점")
print(f"최저점  : {min(scores)}점")
print(f"평균    : {sum(scores) / len(scores):.1f}점")
print()
print("--- 점수 목록 ---")
for i in range(len(names)):
    print(f"  {names[i]}: {scores[i]}점")
```
