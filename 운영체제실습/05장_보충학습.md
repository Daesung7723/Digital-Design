# 05장 보충학습
- 대상: 셸 개념이 처음인 초보 학습자
- 목적: Bash 셸의 역할을 이해하고 변수, 파이프, 리다이렉션, alias, history를 사용할 수 있도록 한다.

## 1. 보충학습 목표
- 셸이 무엇인지 이해한다.
- 환경 변수와 지역 변수의 차이를 간단히 이해한다.
- 파이프(`|`)를 사용해 명령을 연결할 수 있다.
- 리다이렉션을 사용해 출력 결과를 파일로 저장할 수 있다.
- alias와 history를 활용할 수 있다.

## 2. 본문과 연결되는 내용
- 5장 본문은 셸 종류, 셸 변수, 리다이렉션, 파이프, alias, history, 프롬프트, 환경 설정 파일을 다룬다.
- Bash와 Dash의 차이, `env`, `set`, `echo`, `alias`, `history`, `PS1` 등이 포함되어 있다.
- 환경 설정 파일: `/etc/profile`, `~/.bashaliases`, `~/.profile` 등

## 3. 핵심 정리
- 셸은 사용자가 입력한 명령을 해석해 커널에 전달하는 프로그램이다.
- Bash는 Ubuntu에서 기본으로 사용하는 셸이다.
- 변수는 값을 저장하는 이름표이다.
- 파이프는 앞 명령의 출력을 뒤 명령의 입력으로 연결한다.
- 리다이렉션은 출력 결과를 화면 대신 파일로 보낸다.

## 4. 보충학습 내용 1: 변수 확인
- 환경 변수 보기
  ```bash
  env
  ```
- 셸 변수까지 포함해서 보기
  ```bash
  set | more
  ```
- 자주 쓰는 변수 출력
  ```bash
  echo $HOME
  echo $USER
  echo $PATH
  echo $HOSTNAME
  ```

## 5. 보충학습 내용 2: 변수 만들기
- 지역 변수 만들기
  ```bash
  MYNAME=ubuntu
  echo $MYNAME
  ```
- 환경 변수로 내보내기
  ```bash
  export MYNAME
  ```
- 한 번에 설정
  ```bash
  export MYOS=Ubuntu
  echo $MYOS
  ```

## 6. 보충학습 내용 3: 파이프 (|)
- 파이프는 앞 명령의 결과를 뒤 명령에 넘겨주는 기능이다.
- 기본 예시
  ```bash
  ls /etc | more
  ```
- 특정 단어 필터링
  ```bash
  ls /etc | grep conf
  cat /etc/services | grep http
  ```
- history와 함께 사용
  ```bash
  history | grep ls
  ```
- 활용 팁
  - 출력이 길 때 `| more` 또는 `| less`를 붙이면 페이지 단위로 볼 수 있다.
  - `| grep 단어`를 붙이면 원하는 내용만 필터링할 수 있다.

## 7. 보충학습 내용 4: 리다이렉션
- 표준 출력 저장 (덮어쓰기)
  ```bash
  echo hello > hello.txt
  cat hello.txt
  ```
- 내용 이어 붙이기
  ```bash
  echo world >> hello.txt
  cat hello.txt
  ```
- `>`와 `>>`의 차이
  - `>`: 기존 내용을 지우고 새로 저장
  - `>>`: 기존 내용에 이어서 저장

- 에러 출력 분리
  ```bash
  ls /tmp > ok.txt
  ls /no_such_dir 2> err.txt
  cat ok.txt
  cat err.txt
  ```
- 표준 출력 + 에러 출력 함께 저장
  ```bash
  ls /tmp /no_such_dir > all.txt 2>&1
  cat all.txt
  ```

## 8. 보충학습 내용 5: alias와 history
- 별명 만들기
  ```bash
  alias ll='ls -alF'
  alias c='clear'
  ```
- 사용
  ```bash
  ll
  c
  ```
- 등록된 alias 확인
  ```bash
  alias
  ```
- 명령 기록 보기
  ```bash
  history
  ```
- 마지막 명령 다시 실행
  ```bash
  !!
  ```
- history에서 특정 명령 찾기
  ```bash
  history | grep ls
  ```

## 9. 보충학습 내용 6: 환경 설정 파일 편집
- 목적: alias를 영구 적용하려면 설정 파일에 저장해야 한다.
- 개인 alias 설정 파일 열기 (교재 기준 파일명)
  ```bash
  nano ~/.bashaliases
  ```
- 예시 내용 입력
  ```bash
  alias ll='ls -alF'
  alias c='clear'
  ```
- 저장: `Ctrl + O` → `Enter` → `Ctrl + X`

- 적용
  ```bash
  source ~/.bashaliases
  ```

- 참고
  - 교재 표기는 `.bashaliases`이다.
  - Ubuntu 실제 환경에서는 `.bash_aliases`를 쓰는 경우도 있다.
  - 두 파일명 모두 동작하므로, 교재 실습에서는 `.bashaliases`로 통일한다.

- `.profile` 수정 예시 (umask 설정)
  ```bash
  nano ~/.profile
  ```

## 11. 체크리스트
- 셸의 역할을 설명할 수 있다.
- `echo $HOME`, `echo $PATH`를 실행할 수 있다.
- 파이프(`|`)로 명령을 연결할 수 있다.
- `>`와 `>>` 차이를 이해하고 사용할 수 있다.
- alias를 만들고 설정 파일에 저장할 수 있다.
- history를 확인하고 활용할 수 있다.

## 12. 주의사항
- `>`는 기존 파일 내용을 덮어쓴다. 중요한 파일에 사용 시 주의한다.
- alias는 현재 셸에서만 임시로 적용된다.
- 영구 적용하려면 반드시 설정 파일에 저장하고 `source`로 적용해야 한다.
- `PATH` 변수는 시스템 동작에 중요하므로 초보자는 함부로 수정하지 않는다.
- 시스템 설정 파일(`/etc/profile` 등)을 수정할 때는 반드시 `sudo nano`를 사용한다.
