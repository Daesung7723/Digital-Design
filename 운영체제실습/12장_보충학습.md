# 12장 보충학습
- 대상: C 언어 컴파일과 개발 환경이 처음인 초보 학습자
- 목적: gcc로 C 프로그램을 컴파일하고 실행할 수 있으며, Makefile의 개념을 이해하도록 한다.

## 1. 보충학습 목표
- 프로그래밍 언어와 컴파일의 개념을 이해한다.
- `gcc`로 C 소스 파일을 컴파일하고 실행할 수 있다.
- 여러 파일로 구성된 프로그램을 컴파일하는 방법을 이해한다.
- `Makefile`의 기본 구조를 이해한다.
- 파이썬 스크립트를 실행할 수 있다.

## 2. 본문과 연결되는 내용
- 12장 본문은 프로그래밍 언어 종류, C/C++ 컴파일(`gcc`, `g++`), 라이브러리, `make`, Python 실행을 다룬다.
- `gcc`, `-o`, `-c`, `g++`, `make`, `Makefile`, `python3`이 포함되어 있다.

## 3. 핵심 정리
- 컴파일: 사람이 작성한 소스 코드를 컴퓨터가 실행할 수 있는 형태로 변환하는 과정이다.
- `gcc`는 리눅스에서 C 언어를 컴파일하는 기본 도구이다.
- `make`는 여러 파일로 구성된 프로젝트를 자동으로 빌드하는 도구이다.
- Python은 컴파일 없이 `python3` 명령으로 바로 실행할 수 있다.

## 4. 보충학습 내용 1: gcc 기본 사용
- 설치 확인
  ```bash
  gcc --version
  ```
- C 소스 파일 작성
  ```bash
  nano ch12-1.c
  ```
  ```c
  #include <stdio.h>
  int main() {
      printf("Ubuntu Linux\n");
      printf("Ch12 C Program Test\n");
      return 0;
  }
  ```
- 컴파일 (기본 출력 파일: `a.out`)
  ```bash
  gcc ch12-1.c
  ./a.out
  ```
- 출력 파일 이름 지정
  ```bash
  gcc ch12-1.c -o ch12-1
  ./ch12-1
  ```

## 5. 보충학습 내용 2: 여러 파일 컴파일
- 소스 파일 구성 예시: `main.c`, `add.c`, `sub.c`
- 오브젝트 파일로 각각 컴파일
  ```bash
  gcc -c main.c
  gcc -c add.c
  gcc -c sub.c
  ```
- 링크하여 최종 실행 파일 생성
  ```bash
  gcc main.o add.o sub.o -o mymath
  ./mymath
  ```

## 6. 보충학습 내용 3: Makefile
- 목적: 여러 파일을 매번 하나씩 컴파일하지 않고 `make` 명령 한 번으로 자동화
- 설치 확인
  ```bash
  make --version
  ```
- Makefile 예시 (nano로 작성)
  ```bash
  nano Makefile
  ```
  ```makefile
  mymath: main.o add.o sub.o
      gcc main.o add.o sub.o -o mymath
  main.o: main.c
      gcc -c main.c
  add.o: add.c
      gcc -c add.c
  sub.o: sub.c
      gcc -c sub.c
  ```
  - 주의: 들여쓰기는 반드시 탭(Tab) 문자를 사용한다.

- make 실행
  ```bash
  make
  ./mymath
  ```
- 변경된 파일만 재컴파일 (자동 처리)
  ```bash
  nano add.c    # 내용 수정
  make          # 변경된 부분만 다시 컴파일
  ```

## 7. 보충학습 내용 4: C++ 컴파일
- C++ 소스 파일 작성
  ```bash
  nano ch12-2.cpp
  ```
  ```cpp
  #include <iostream>
  using namespace std;
  int main() {
      cout << "Hanbit Academy" << endl;
      return 0;
  }
  ```
- `g++`으로 컴파일
  ```bash
  g++ ch12-2.cpp -o ch12-2
  ./ch12-2
  ```

## 8. 보충학습 내용 5: Python 실행
- Python 버전 확인
  ```bash
  python3 --version
  ```
- 대화형 모드 실행
  ```bash
  python3
  ```
  - 종료: `exit()` 또는 `Ctrl + D`
- 스크립트 파일 실행
  ```bash
  nano hello.py
  ```
  ```python
  print("Hello, Ubuntu Linux!")
  ```
  ```bash
  python3 hello.py
  ```

## 10. 체크리스트
- `gcc`로 C 소스를 컴파일하고 실행할 수 있다.
- `-o` 옵션으로 출력 파일 이름을 지정할 수 있다.
- `make` 명령으로 빌드할 수 있다.
- `python3`으로 스크립트를 실행할 수 있다.

## 11. 주의사항
- Makefile의 들여쓰기는 반드시 탭(Tab) 문자이다. 스페이스로 작성하면 오류가 발생한다.
- `gcc`가 없으면 `sudo apt install build-essential -y`로 설치한다.
- `g++`이 없으면 같은 패키지에 포함되어 있다.
