# 03장 보충학습

- 대상: 파일과 디렉터리 개념이 아직 익숙하지 않은 초보 학습자
- 목적: 경로, 디렉터리 이동, 파일 생성/복사/이동/삭제를 확실히 익히도록 한다.

## 1. 보충학습 목표

- 절대경로와 상대경로를 구분할 수 있다.
- `pwd`, `cd`, `ls`, `mkdir`, `rmdir`를 사용할 수 있다.
- `touch`, `cat`, `more`, `less`, `head`, `tail`을 사용할 수 있다.
- `cp`, `mv`, `rm`, `ln -s`의 기본 사용법을 익힌다.

## 2. 본문과 연결되는 내용

- 3장 본문은 파일 시스템, 파일 종류, 경로, 디렉터리 명령, 파일 명령, 링크를 다룬다.
- `pwd`, `cd`, `ls`, `mkdir`, `rmdir`, `cat`, `cp`, `mv`, `rm`, `ln -s`가 포함되어 있다.
- 교재 실습 폴더 구조: `~/study/ch03` 아래에서 실습 진행

## 3. 핵심 정리

- 디렉터리는 파일을 담는 폴더이다.
- 현재 작업 중인 위치를 현재 디렉터리(작업 디렉터리)라고 한다.
- `.`은 현재 디렉터리, `..`은 상위 디렉터리, `~`는 홈 디렉터리이다.
- 파일 작업은 "위치 확인 → 이동 → 생성 → 확인 → 정리" 순서로 연습하는 것이 좋다.

## 4. 보충학습 내용 1: 경로 이해

- 절대경로
  - `/`부터 시작하는 전체 경로
  - 예: `/home/user1`, `/etc/hosts`
- 상대경로
  - 현재 위치를 기준으로 한 경로
  - 예: `study/ch03`, `../etc`
- 자주 쓰는 기호
  - `.` : 현재 디렉터리
  - `..` : 상위 디렉터리
  - `~` : 홈 디렉터리 (`/home/user1`)

## 5. 보충학습 내용 2: 디렉터리 이동

- 현재 위치 보기
  
  ```bash
  pwd
  ```
  
- 홈 디렉터리로 이동
  
  ```bash
  cd
  ```
  
- 상위 디렉터리로 이동
  
  ```bash
  cd ..
  ```
  
- 특정 디렉터리로 이동
  
  ```bash
  cd /tmp
  cd ~/study/ch03
  ```
  

## 6. 보충학습 내용 3: 파일 목록 확인

- 기본 목록
  
  ```bash
  ls
  ```
  
- 숨김 파일 포함
  
  ```bash
  ls -a
  ```
  
- 자세히 보기
  
  ```bash
  ls -l
  ```
  
- 파일 종류 표시
  
  ```bash
  ls -F
  ```
  

## 7. 보충학습 내용 4: 디렉터리 만들기와 삭제

- 디렉터리 만들기
  
  ```bash
  mkdir study
  ```
  
- 여러 단계 한 번에 만들기
  
  ```bash
  mkdir -p ~/study/ch03
  ```
  
- 하위 디렉터리 함께 만들기 (교재 실습 기준)
  
  ```bash
  cd ~/study/ch03
  mkdir one
  mkdir me you
  ls
  ```
  
- 빈 디렉터리 삭제
  
  ```bash
  rmdir me
  ```
  
- 주의
  - `rmdir`은 빈 디렉터리만 삭제 가능하다.
  - 파일이 있는 디렉터리는 `rm -r` 사용

## 8. 보충학습 내용 5: 파일 만들기와 내용 보기

- 빈 파일 만들기
  
  ```bash
  touch hello.txt
  ls -l
  ```
  
- 파일 내용 보기
  
  ```bash
  cat hello.txt
  cat -n hello.txt
  ```
  
- 긴 파일 보기
  
  ```bash
  less /etc/services
  more /etc/services
  ```
  
- `less` 화면에서 자주 쓰는 키
  - 아래로 이동: `Space` 또는 `Enter`
  - 위로 이동: `k`
  - 검색: `/HTTP`
  - 다음 결과: `n`
  - 종료: `q`
- 파일 앞부분/뒷부분만 보기
  
  ```bash
  head /etc/services
  tail /etc/services
  tail -20 /etc/services
  ```
  

## 9. 보충학습 내용 6: 파일 복사, 이동, 삭제

- 파일 복사
  
  ```bash
  cp hello.txt hello.bak
  ```
  
- 디렉터리 복사
  
  ```bash
  cp -r one one_backup
  ```
  
- 파일 이동 또는 이름 바꾸기
  
  ```bash
  mv hello.bak backup.txt
  ```
  
- 파일 삭제
  
  ```bash
  rm backup.txt
  ```
  
- 삭제 전 확인 (-i 옵션)
  
  ```bash
  rm -i backup.txt
  ```
  

## 10. 보충학습 내용 7: 링크 맛보기

- 심볼릭 링크 만들기
  
  ```bash
  ln -s hello.txt hello.link
  ```
  
- 확인 (`l` 표시가 있으면 심볼릭 링크)
  
  ```bash
  ls -l
  ```
  

## 11. 추가 실습

- 실습 1: 실습 폴더 만들기
  
  ```bash
  mkdir -p ~/study/ch03
  cd ~/study/ch03
  pwd
  ```
  
- 실습 2: 파일 만들기
  
  ```bash
  touch test1.txt
  ls -l
  cat test1.txt
  ```
  
- 실습 3: 파일 내용 보기
  
  ```bash
  less /etc/services
  head /etc/services
  tail /etc/services
  ```
  
- 실습 4: 복사와 이동
  
  ```bash
  cp test1.txt test2.txt
  mv test2.txt test3.txt
  ls -l
  ```
  
- 실습 5: 삭제
  
  ```bash
  rm -i test3.txt
  ls
  ```
  
- 실습 6: 링크 만들기
  
  ```bash
  ln -s test1.txt test1.link
  ls -l
  ```
  

## 12. 체크리스트

- `pwd`와 `cd`를 사용할 수 있다.
- 절대경로와 상대경로를 구분하여 사용할 수 있다.
- `mkdir`, `rmdir`, `touch`, `cp`, `mv`, `rm`을 사용할 수 있다.
- `less`, `head`, `tail`로 파일 내용을 확인할 수 있다.
- 심볼릭 링크를 만들 수 있다.

## 13. 주의사항

- `rm`은 삭제 후 복구가 어렵다. 삭제 전 `ls`로 대상을 먼저 확인하는 습관을 들인다.
- `rmdir`은 빈 디렉터리만 삭제 가능하다.
- `cp`, `mv` 실행 전 대상 파일 이름이 이미 존재하는지 확인한다.
- `less` 화면에서 나오지 못하면 `q`를 누른다.

## 14. 3장 보충학습 완료 기준
