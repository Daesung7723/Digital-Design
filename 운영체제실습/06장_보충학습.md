# 06장 보충학습
- 대상: 파일 권한 개념이 처음인 초보 학습자
- 목적: 권한 표시를 읽고, chmod로 권한을 변경할 수 있도록 한다.

## 1. 보충학습 목표
- `ls -l` 출력에서 권한 표시를 읽을 수 있다.
- 기호 방식과 숫자 방식으로 `chmod`를 사용할 수 있다.
- `umask`의 개념을 이해한다.
- SetUID, SetGID, Sticky Bit의 개념을 간단히 이해한다.

## 2. 본문과 연결되는 내용
- 6장 본문은 파일 권한, `chmod`, `umask`, 특수 권한(SetUID/SetGID/Sticky Bit)을 다룬다.
- `ls -l` 출력의 권한 필드 해석, 기호/숫자 방식 `chmod`, `chown` 사용법이 포함되어 있다.

## 3. 핵심 정리
- 권한은 파일의 읽기(r), 쓰기(w), 실행(x) 여부를 소유자/그룹/기타 사용자별로 나타낸다.
- `ls -l` 첫 번째 필드 `-rwxr-xr--`에서 앞 3자리: 소유자, 중간 3자리: 그룹, 마지막 3자리: 기타 사용자.
- 숫자 권한: `r=4`, `w=2`, `x=1` 이며 합산해서 표현한다.

## 4. 보충학습 내용 1: 권한 표 읽기
- `ls -l` 출력 예시
  ```bash
  -rw-r--r-- 1 user1 user1 1024 Mar 17 12:00 hello.txt
  ```

- 권한 필드 해석
  | 위치 | 표시 | 의미 |
  |---|---|---|
  | 1번째 | `-` | 일반 파일 (`d`이면 디렉터리) |
  | 2~4번째 | `rw-` | 소유자: 읽기, 쓰기 가능 |
  | 5~7번째 | `r--` | 그룹: 읽기만 가능 |
  | 8~10번째 | `r--` | 기타 사용자: 읽기만 가능 |

- 숫자 권한 빠른 참조표
  | 숫자 | 권한 | 의미 |
  |---|---|---|
  | 7 | rwx | 읽기 + 쓰기 + 실행 |
  | 6 | rw- | 읽기 + 쓰기 |
  | 5 | r-x | 읽기 + 실행 |
  | 4 | r-- | 읽기만 |
  | 0 | --- | 권한 없음 |

## 5. 보충학습 내용 2: chmod 기호 방식
- 형식: `chmod 대상+/-/=권한 파일`
- 대상 기호
  - `u`: 소유자
  - `g`: 그룹
  - `o`: 기타 사용자
  - `a`: 전체

- 예시
  ```bash
  chmod u+x hello.txt      # 소유자에 실행 권한 추가
  chmod g-w hello.txt      # 그룹의 쓰기 권한 제거
  chmod o=r hello.txt      # 기타 사용자를 읽기만으로 설정
  chmod a-x hello.txt      # 전체에서 실행 권한 제거
  ```

## 6. 보충학습 내용 3: chmod 숫자 방식
- 형식: `chmod 숫자3자리 파일`
- 자주 쓰는 숫자 권한 조합

  | 명령 | 의미 |
  |---|---|
  | `chmod 644 파일` | 소유자: rw-, 그룹: r--, 기타: r-- |
  | `chmod 755 파일` | 소유자: rwx, 그룹: r-x, 기타: r-x |
  | `chmod 600 파일` | 소유자: rw-, 그룹: ---, 기타: --- |
  | `chmod 777 파일` | 모두 rwx (보안상 권장하지 않음) |

- 예시
  ```bash
  chmod 644 hello.txt
  ls -l hello.txt
  chmod 755 myscript.sh
  ls -l myscript.sh
  ```

## 7. 보충학습 내용 4: umask
- 새 파일 생성 시 기본 권한을 제한하는 설정이다.
- 현재 umask 확인
  ```bash
  umask
  ```
- 일반적으로 `0022`가 기본값이다.
  - 파일 기본 권한 `666 - 022 = 644`
  - 디렉터리 기본 권한 `777 - 022 = 755`
- umask 변경 예시
  ```bash
  umask 002
  touch newfile.txt
  ls -l newfile.txt
  ```

## 8. 보충학습 내용 5: 특수 권한 맛보기
- SetUID
  - 파일 실행 시 소유자 권한으로 실행됨.
  - 대표 예: `passwd` 명령.
  - 확인 방법
    ```bash
    ls -l /usr/bin/passwd
    ```
  - `s` 표시 확인: `-rwsr-xr-x`

- Sticky Bit
  - 디렉터리에 설정 시 본인 파일만 삭제 가능.
  - 대표 예: `/tmp` 디렉터리.
  - 확인 방법
    ```bash
    ls -ld /tmp
    ```
  - `t` 표시 확인: `drwxrwxrwt`

## 10. 체크리스트
- `ls -l` 출력에서 권한 필드를 읽을 수 있다.
- 기호 방식과 숫자 방식으로 `chmod`를 사용할 수 있다.
- `644`, `755` 숫자 권한의 의미를 설명할 수 있다.
- umask의 역할을 설명할 수 있다.
- SetUID와 Sticky Bit의 예를 하나씩 말할 수 있다.

## 11. 주의사항
- `chmod 777`은 보안상 권장하지 않는다.
- SetUID 설정은 보안 위험이 있으므로 꼭 필요한 경우에만 사용한다.
- 시스템 파일의 권한은 함부로 변경하지 않는다.
