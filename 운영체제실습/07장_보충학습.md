# 07장 보충학습
- 대상: 파일 검색과 텍스트 처리가 처음인 초보 학습자
- 목적: `find`, `grep`, `sort`, `uniq`를 사용해 파일과 내용을 찾고 정리할 수 있도록 한다.

## 1. 보충학습 목표
- `find`로 파일을 이름, 종류, 크기 기준으로 검색할 수 있다.
- `grep`으로 파일 내용에서 원하는 단어를 찾을 수 있다.
- `sort`, `uniq`로 텍스트를 정렬하고 중복을 제거할 수 있다.
- `diff`, `cut`, `split`의 기본 사용법을 익힌다.

## 2. 본문과 연결되는 내용
- 7장 본문은 문자 코드, `find`, `grep`, `sort`, `uniq`, `diff`, `split`, `cut`, `paste`를 다룬다.
- 파일 검색, 내용 검색, 텍스트 정렬, 파일 비교가 포함되어 있다.

## 3. 핵심 정리: 명령 선택 가이드
| 목적 | 명령 |
|---|---|
| 파일 이름으로 찾기 | `find` |
| 파일 내용에서 단어 찾기 | `grep` |
| 텍스트 정렬 | `sort` |
| 중복 제거 | `uniq` |
| 파일 두 개 비교 | `diff` |
| 파일 특정 열 추출 | `cut` |
| 파일 분할 | `split` |

## 4. 보충학습 내용 1: find
- 기본 형식
  ```bash
  find 검색위치 옵션 조건
  ```
- 파일 이름으로 검색
  ```bash
  find /etc -name "hosts"
  find . -name "*.txt"
  ```
- 파일 종류로 검색
  ```bash
  find /etc -type f        # 일반 파일
  find /etc -type d        # 디렉터리
  ```
- 크기로 검색
  ```bash
  find /usr/bin -size +1M  # 1MB 초과
  ```
- 검색 후 명령 실행
  ```bash
  find . -name "*.txt" -exec ls -l {} \;
  ```
- 명령어 위치 확인
  ```bash
  whereis mv
  which mv
  ```

## 5. 보충학습 내용 2: grep
- 기본 형식
  ```bash
  grep 패턴 파일
  ```
- 기본 검색
  ```bash
  grep "http" /etc/services
  ```
- 줄 번호 표시
  ```bash
  grep -n "http" /etc/services
  ```
- 대소문자 무시
  ```bash
  grep -i "linux" sample.txt
  ```
- 패턴이 없는 줄 검색
  ```bash
  grep -v "http" /etc/services
  ```
- 파이프와 함께 사용
  ```bash
  ls /etc | grep conf
  cat /etc/services | grep ftp
  ```

## 6. 보충학습 내용 3: sort
- 기본 정렬
  ```bash
  sort sample.txt
  ```
- 역순 정렬
  ```bash
  sort -r sample.txt
  ```
- 대소문자 무시
  ```bash
  sort -f sample.txt
  ```
- 중복 제거하며 정렬
  ```bash
  sort -u sample.txt
  ```
- 결과를 파일로 저장
  ```bash
  sort sample.txt -o sorted.txt
  ```

## 7. 보충학습 내용 4: uniq
- 연속 중복 제거 (sort 후 사용 권장)
  ```bash
  sort sample.txt | uniq
  ```
- 중복 횟수 표시
  ```bash
  sort sample.txt | uniq -c
  ```
- 중복된 줄만 출력
  ```bash
  sort sample.txt | uniq -d
  ```
- 중복 없는 줄만 출력
  ```bash
  sort sample.txt | uniq -u
  ```

## 8. 보충학습 내용 5: diff
- 두 파일 비교
  ```bash
  diff file1.txt file2.txt
  ```
- 결과 읽는 법
  - `<`: 첫 번째 파일에만 있는 줄
  - `>`: 두 번째 파일에만 있는 줄
- 대소문자 무시 비교
  ```bash
  diff -i file1.txt file2.txt
  ```

## 9. 추가 실습
- 실습 1: find 검색
  ```bash
  find /etc -name "hosts"
  find . -name "*.txt"
  find /usr/bin -size +1M
  ```
- 실습 2: grep 검색
  ```bash
  grep "ftp" /etc/services
  grep -n "ftp" /etc/services
  grep -i "linux" /etc/services
  ```
- 실습 3: sort와 uniq
  ```bash
  sort /etc/passwd | head
  sort /etc/passwd | uniq -c | head
  ```
- 실습 4: diff 비교
  ```bash
  cp /etc/hosts hosts1.txt
  cp hosts1.txt hosts2.txt
  echo "test line" >> hosts2.txt
  diff hosts1.txt hosts2.txt
  ```

## 10. 체크리스트
- `find`로 파일 이름, 종류, 크기 기준 검색을 할 수 있다.
- `grep`으로 파일 내용에서 단어를 찾을 수 있다.
- `sort`와 `uniq`를 파이프로 연결해 사용할 수 있다.
- `diff`로 두 파일의 차이를 확인할 수 있다.

## 11. 주의사항
- `find /`는 전체 시스템을 검색하므로 시간이 오래 걸릴 수 있다.
- `uniq`는 연속된 중복만 제거하므로 반드시 `sort` 후 사용한다.
- 정규식 패턴에서 특수문자(`.`, `*`)는 의미가 다를 수 있다.
