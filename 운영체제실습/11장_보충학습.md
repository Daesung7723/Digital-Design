# 11장 보충학습
- 대상: 셸 스크립트를 처음 작성하는 초보 학습자
- 목적: 셸 스크립트의 기본 구조와 변수, 조건문, 반복문을 익혀 간단한 스크립트를 작성할 수 있도록 한다.

## 1. 보충학습 목표
- 셸 스크립트를 만들고 실행할 수 있다.
- 변수, `read`, 위치 매개변수를 사용할 수 있다.
- `if`, `case`, `for`, `while`을 사용할 수 있다.
- 디버깅 옵션(`bash -x`)을 사용할 수 있다.

## 2. 본문과 연결되는 내용
- 11장 본문은 스크립트 작성/실행, 변수, 산술 연산, 조건, 반복, 함수, 디버깅을 다룬다.
- `#!/bin/bash`, `chmod`, `read`, `if`, `case`, `for`, `while`, 함수, `bash -x`가 포함되어 있다.

## 3. 핵심 정리
- 셸 스크립트는 명령어를 파일에 저장하고 한 번에 실행하는 방식이다.
- 첫 줄에 반드시 `#!/bin/bash`를 작성한다.
- 실행 전 `chmod +x` 로 실행 권한을 부여한다.
- 변수에 값을 대입할 때 `=` 양쪽에 공백이 없어야 한다.

## 4. 보충학습 내용 1: 스크립트 기본 구조
- 스크립트 작성 (nano 사용)
  ```bash
  nano script01.sh
  ```
- 파일 내용 예시
  ```bash
  #!/bin/bash
  echo "Hello, Linux!"
  echo "현재 사용자: $USER"
  echo "현재 디렉터리: $PWD"
  ```
- 실행 권한 부여 및 실행
  ```bash
  chmod +x script01.sh
  ./script01.sh
  ```

## 5. 보충학습 내용 2: 변수와 입력
- 변수 사용
  ```bash
  #!/bin/bash
  NAME="Ubuntu"
  echo "운영체제: $NAME"
  ```
- 사용자 입력 받기
  ```bash
  #!/bin/bash
  read -p "이름을 입력하세요: " USERNAME
  echo "안녕하세요, $USERNAME 님!"
  ```
- 위치 매개변수 (스크립트 실행 시 인수 전달)
  ```bash
  #!/bin/bash
  echo "첫 번째 인수: $1"
  echo "두 번째 인수: $2"
  echo "전체 인수 수: $#"
  ```
  - 실행 예: `./script.sh Ubuntu Linux`

## 6. 보충학습 내용 3: 산술 연산
- `let` 또는 `$(( ))` 사용
  ```bash
  #!/bin/bash
  A=10
  B=3
  let SUM=A+B
  echo "합계: $SUM"
  echo "나머지: $((A % B))"
  ```

## 7. 보충학습 내용 4: 조건문
- `if` 기본 구조
  ```bash
  #!/bin/bash
  SCORE=85
  if [ $SCORE -ge 90 ]; then
      echo "Best"
  elif [ $SCORE -ge 80 ]; then
      echo "Good"
  else
      echo "Try again"
  fi
  ```

- 자주 쓰는 비교 연산자

  | 연산자 | 의미 |
  |---|---|
  | `-eq` | 같다 |
  | `-ne` | 다르다 |
  | `-gt` | 크다 |
  | `-ge` | 크거나 같다 |
  | `-lt` | 작다 |
  | `-le` | 작거나 같다 |

- `case` 구조
  ```bash
  #!/bin/bash
  read -p "요일을 입력하세요 (mon/fri): " DAY
  case $DAY in
    mon) echo "월요일입니다." ;;
    fri) echo "금요일입니다." ;;
    *)   echo "기타 요일입니다." ;;
  esac
  ```

## 8. 보충학습 내용 5: 반복문
- `for` 반복문
  ```bash
  #!/bin/bash
  for i in 1 2 3 4 5; do
      echo "번호: $i"
  done
  ```
- 범위 지정
  ```bash
  #!/bin/bash
  for i in $(seq 1 5); do
      echo "번호: $i"
  done
  ```
- `while` 반복문
  ```bash
  #!/bin/bash
  COUNT=1
  while [ $COUNT -le 5 ]; do
      echo "카운트: $COUNT"
      let COUNT=COUNT+1
  done
  ```

## 9. 보충학습 내용 6: 디버깅
- 디버그 모드 실행
  ```bash
  bash -x script01.sh
  ```
- 실행 중 각 명령이 어떻게 처리되는지 `+`와 함께 표시되어 오류를 찾기 쉽다.

- 실습 2: 입력 받는 스크립트

  ./script04.sh

- 실습 5: 디버깅
  ```bash

  ```

## 11. 체크리스트
- `#!/bin/bash`로 시작하는 스크립트를 만들고 실행할 수 있다.
- 변수를 만들고 출력할 수 있다.
- `read`로 입력을 받을 수 있다.
- `if`, `for`, `while`을 사용할 수 있다.
- `bash -x`로 디버깅할 수 있다.

## 12. 주의사항
- `=` 양쪽에 공백이 있으면 오류가 발생한다. (`NAME=Ubuntu` 가 맞음)
- `[ ]` 안에서 비교 연산자와 값 사이에는 공백이 필요하다. (`[ $A -eq 10 ]`)
- `fi`, `done`, `esac` 등 블록 종료 키워드를 빠뜨리지 않는다.
- 실행 권한이 없으면 `Permission denied` 오류가 발생한다. `chmod +x`를 먼저 실행한다.
