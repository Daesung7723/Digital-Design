# 04장 보충학습
- 대상: 텍스트 편집기를 처음 사용하는 초보 학습자
- 목적: nano를 중심으로 파일을 열고, 편집하고, 저장하고, 종료할 수 있도록 한다.
- 참고: 본 강의에서는 vi 대신 nano를 주 편집기로 사용한다.

## 1. 보충학습 목표
- 텍스트 편집기의 역할을 이해한다.
- nano로 파일을 열고, 편집하고, 저장하고, 종료할 수 있다.
- nano의 자주 쓰는 단축키를 익힌다.
- vi의 최소한의 사용법(탈출 방법)을 알아둔다.

## 2. 본문과 연결되는 내용
- 4장 본문은 vi와 nano 사용법을 다룬다.
- 본 강의에서는 vi를 nano로 대체하여 실습한다.
- nano는 4장 3절에 별도 소개되어 있다.

## 3. 핵심 정리
- nano는 단축키가 화면 아래에 항상 표시되어 초보자가 쉽게 사용할 수 있다.
- `^`는 `Ctrl`을 의미한다. (예: `^O` = `Ctrl + O`)
- nano에는 vi와 달리 별도의 모드 전환이 없다. 열면 바로 입력할 수 있다.

## 4. 보충학습 내용 1: nano 단축키 한눈에 보기

| 기능 | 단축키 |
|---|---|
| 저장 | `Ctrl + O` → `Enter` |
| 종료 | `Ctrl + X` |
| 잘라내기 (한 줄) | `Ctrl + K` |
| 붙여넣기 | `Ctrl + U` |
| 검색 | `Ctrl + W` |
| 다음 검색 결과 | `Alt + W` |
| 줄 번호 표시/숨김 | `Alt + N` |
| 실행 취소 | `Alt + U` |
| 다시 실행 | `Alt + E` |
| 커서 위치 확인 | `Ctrl + C` |

## 5. 보충학습 내용 2: nano 기본 사용 흐름
- 파일 열기
  ```bash
  nano practice.txt
  ```

- 연습 순서
  1. 파일이 열리면 문장 3줄 입력
  2. `Ctrl + W` 로 단어 검색
  3. `Ctrl + K` 로 한 줄 잘라내기
  4. `Ctrl + U` 로 붙여넣기
  5. `Alt + N` 으로 줄 번호 켜기
  6. `Ctrl + O` 로 저장 → `Enter`
  7. `Ctrl + X` 로 종료

- 저장 확인
  ```bash
  cat practice.txt
  ```

## 6. 보충학습 내용 3: nano 검색 실습
- 긴 파일에서 특정 단어 찾기
  ```bash
  nano /etc/services
  ```
  - `Ctrl + W` → `http` 입력 → `Enter`
  - `Alt + W` 로 다음 검색 결과 이동
  - `Ctrl + X` 로 종료 (저장 여부 묻는 경우 `N` 입력)

## 7. 보충학습 내용 4: nano 환경 설정 파일 편집 실습
- 5장, 6장 이후부터 설정 파일을 직접 수정하는 일이 많아진다.
- 연습: 개인 설정 파일에 alias 추가
  ```bash
  nano ~/.bashaliases
  ```
  - 아래 내용 입력
    ```bash
    alias ll='ls -alF'
    alias c='clear'
    ```
  - `Ctrl + O` → `Enter` → `Ctrl + X`

## 8. 보충학습 내용 5: vi 최소 사용법 (비상시 대비)
- nano가 없는 환경이거나 특정 시스템 작업에서 vi가 자동으로 열릴 수 있다.
- 이 경우를 대비해 아래 두 가지만 기억한다.

| 상황 | 명령 |
|---|---|
| 저장 없이 강제 종료 | `Esc` → `:q!` → `Enter` |
| 저장 후 종료 | `Esc` → `:wq` → `Enter` |

- 참고
  - vi가 열리면 글자가 입력되지 않는 경우가 있다.
  - 이때는 당황하지 말고 `Esc` 를 먼저 누른 뒤 `:q!` 로 탈출한다.

## 9. 추가 실습
- 실습 1: nano로 파일 만들기
  ```bash
  nano memo.txt
  ```
  - 오늘 날짜와 이름 입력
  - `Ctrl + O` → `Enter` → `Ctrl + X`
  - `cat memo.txt`

- 실습 2: 잘라내기/붙여넣기 연습
  ```bash
  nano memo.txt
  ```
  - 첫 번째 줄로 이동
  - `Ctrl + K` (잘라내기)
  - 마지막 줄로 이동
  - `Ctrl + U` (붙여넣기)
  - `Ctrl + O` → `Enter` → `Ctrl + X`

- 실습 3: 검색 연습
  ```bash
  nano /etc/services
  ```
  - `Ctrl + W` → `ftp` → `Enter`
  - `Alt + W` 로 다음 검색
  - `Ctrl + X` → 저장 여부: `N`

- 실습 4: alias 설정 파일 편집
  ```bash
  nano ~/.bashaliases
  ```
  - `alias ll='ls -alF'` 입력
  - `Ctrl + O` → `Enter` → `Ctrl + X`
  - `source ~/.bashaliases`
  - `ll`

## 10. 체크리스트
- nano로 파일을 열고 내용을 입력할 수 있다.
- `Ctrl + O`, `Ctrl + X` 로 저장하고 종료할 수 있다.
- `Ctrl + K`, `Ctrl + U` 로 잘라내기/붙여넣기를 할 수 있다.
- `Ctrl + W` 로 단어를 검색할 수 있다.
- vi가 열렸을 때 `Esc` → `:q!` 로 탈출할 수 있다.

## 11. 주의사항
- nano 종료 시 저장 여부를 물으면: 저장 `Y`, 취소 `N`, 다른 이름 저장 `Ctrl + C`
- 시스템 파일(`/etc/` 아래 파일)을 수정할 때는 반드시 `sudo nano`를 사용한다.
- vi가 열렸을 때 당황하지 않는다. `Esc` → `:q!` 로 먼저 탈출한다.
