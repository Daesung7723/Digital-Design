## 1. 게이트 레벨 최소화 개요

### 학습목표

- 게이트 레벨 최소화가 왜 필요한지 설명할 수 있다.
- 부울 대수를 이용한 간소화의 한계와 카노 맵의 필요성을 이해한다.

---

### 1.1 왜 최소화가 필요한가?

2장에서 배운 부울대수로 논리 회로를 설계하면, 같은 기능을 하는 회로를 다양한 방식으로 표현할 수 있습니다.  
이 중 **게이트 수가 가장 적고, 입력 수가 가장 작은 회로**를 찾는 과정이 **게이트 레벨 최소화**입니다.

$$\text{복잡한 부울식} \xrightarrow{\text{최소화}} \text{간단한 부울식} \xrightarrow{\text{구현}} \text{최적 회로}$$

최소화를 통해 얻는 이점:

- **비용 절감**: 게이트 수가 줄면 IC 칩의 면적과 소재가 줄어듭니다.
- **속도 향상**: 게이트가 적으면 신호가 통과하는 단계가 줄어 처리 속도가 빨라집니다.
- **소비 전력 감소**: 게이트 수가 줄면 소비 전력도 줄어듭니다.

---

### 1.2 부울 대수 간소화의 한계

2장에서 배운 부울 대수를 이용한 간소화는 입력 변수가 적을 때는 유용하지만,  
**변수가 4개 이상으로 늘어나면** 어느 법칙을 어느 순서로 적용해야 하는지 직관적으로 알기 어렵습니다.

```
예) F = A'B'CD + A'BCD' + A'BCD + AB'CD + AB'CD' + ABCD
→ 이 식을 부울 대수만으로 간소화하려면 많은 시행착오가 필요합니다.
```

이 한계를 극복하기 위한 **시각적이고 체계적인 도구**가 바로 **카노 맵(Karnaugh Map, K-map)** 입니다.

---

### 1.3 소프트웨어 합성 도구와 원리 이해

현재 산업 현장에서는 **논리합성 소프트웨어**(Logic Synthesis Tool)가 자동으로 게이트 최적화를 수행합니다.  
따라서 "손으로 K-map을 그릴 일이 없지 않냐"고 생각할 수 있습니다.

그러나 다음 두 가지 이유로 원리 이해는 필수입니다.

- **디버깅 능력**: 도구가 생성한 회로에서 오류가 발생했을 때, 원리를 모르면 원인을 찾을 수 없습니다.
- **설계 판단력**: 소프트웨어가 제시한 결과가 올바른지 검증하려면 엔지니어 스스로 판단할 수 있어야 합니다.

> 💡 **요약**: 도구는 원리를 아는 사람이 더 잘 활용할 수 있습니다.

## 2. 카노 맵 기초

### 학습목표

- 카노 맵의 구조와 인접성의 의미를 설명할 수 있다.
- 2변수, 3변수, 4변수 K-map을 읽고 최소항을 배치할 수 있다.

---

### 2.1 카노 맵이란?

**카노 맵(K-map)** 은 진리표를 **2차원 격자** 형태로 재배치한 것입니다.  
인접한 칸끼리 **정확히 1비트만 다른** 입력값을 갖도록 배치하는 것이 핵심입니다.  
이 인접성을 이용해 "묶을 수 있는 최소항"을 눈으로 바로 파악할 수 있습니다.

---

### 2.2 핵심 개념: 인접성(Adjacency)

K-map에서 **인접한 두 칸**은 입력 변수가 **정확히 1개만 다릅니다.**  
1개만 다른 두 최소항을 묶으면 그 변수를 제거할 수 있습니다.

**예시**: $m_2 = x'yz'$와 $m_3 = x'yz$가 인접

$$m_2 + m_3 = x'yz' + x'yz = x'y(z' + z) = x'y \cdot 1 = x'y$$

$z$ 변수가 사라졌습니다. 이것이 K-map 묶음의 원리입니다.

> ⚠️ K-map의 열 배열은 일반 이진수 순서(00, 01, **10, 11**)가 아니라  
> **그레이 코드 순서(00, 01, 11, 10)** 로 배치됩니다.  
> 이렇게 해야 인접한 칸끼리 1비트만 다른 조건이 유지됩니다.

---

### 2.3 2변수 K-map

입력 변수 $x$, $y$ 두 개이므로 $2^2 = 4$칸

```
      y=0   y=1
x=0 [  0  |  1  ]   → x=0, y=0 : m_0 / x=0, y=1 : m_1
x=1 [  2  |  3  ]   → x=1, y=0 : m_2 / x=1, y=1 : m_3
```

각 칸에 해당 최소항 번호를 기록하고, 함수 출력이 1인 칸에 1을 채웁니다.

---

### 2.4 3변수 K-map

입력 변수 $x$, $y$, $z$ 세 개이므로 $2^3 = 8$칸  
행은 $x$, 열은 $yz$를 그레이 코드 순(00, 01, 11, 10)으로 배치합니다.

```
        yz=00  yz=01  yz=11  yz=10
  x=0 [  0  |  1  |  3  |  2  ]
  x=1 [  4  |  5  |  7  |  6  ]
```

| 칸 번호 | $x$ | $y$ | $z$ | 최소항 |
|:---:|:---:|:---:|:---:|:---:|
| 0 | 0 | 0 | 0 | $x'y'z'$ |
| 1 | 0 | 0 | 1 | $x'y'z$ |
| 2 | 0 | 1 | 0 | $x'yz'$ |
| 3 | 0 | 1 | 1 | $x'yz$ |
| 4 | 1 | 0 | 0 | $xy'z'$ |
| 5 | 1 | 0 | 1 | $xy'z$ |
| 6 | 1 | 1 | 0 | $xyz'$ |
| 7 | 1 | 1 | 1 | $xyz$ |

> 💡 K-map에서 **맨 왼쪽 열과 맨 오른쪽 열도 인접합니다.** (원통형으로 이어진다고 생각하세요)  
> 즉, $yz=00$ 열과 $yz=10$ 열은 1비트($y$만) 차이이므로 인접합니다.

---

### 2.5 4변수 K-map

입력 변수 $w$, $x$, $y$, $z$ 네 개이므로 $2^4 = 16$칸  
행은 $wx$, 열은 $yz$를 각각 그레이 코드 순으로 배치합니다.

```
          yz=00  yz=01  yz=11  yz=10
wx=00  [  0  |  1  |  3  |  2  ]
wx=01  [  4  |  5  |  7  |  6  ]
wx=11  [ 12  | 13  | 15  | 14  ]
wx=10  [  8  |  9  | 11  | 10  ]
```

> ⚠️ 행 순서도 그레이 코드(00, 01, **11, 10**)입니다.  
> 즉, **위 행과 아래 행도 인접합니다.** ($wx=00$행과 $wx=10$행은 인접)  
> 이를 **상하좌우 모두 이어진 도넛 모양**으로 이해하면 편리합니다.

## 3. K-map 최소화 절차

### 학습목표

- K-map에서 최적의 그룹을 선택하는 규칙을 적용할 수 있다.
- 주항(Prime Implicant)의 개념을 이해하고 최소화된 SOP 식을 도출할 수 있다.

---

### 3.1 그룹핑 규칙

K-map에서 1이 채워진 칸들을 묶을 때 반드시 따라야 하는 규칙:

| 규칙 | 내용 |
|---|---|
| **묶음 크기** | 반드시 $1, 2, 4, 8, 16$개 (2의 거듭제곱) |
| **모양** | 직사각형 (정사각형 포함) 형태만 허용 |
| **크기 우선** | 가능한 한 **가장 크게** 묶을수록 변수가 더 많이 제거됨 |
| **중복 허용** | 같은 칸이 여러 그룹에 포함될 수 있음 |
| **래핑(Wrapping)** | 상하, 좌우 경계를 넘어 이어서 묶을 수 있음 |
| **전체 커버** | 출력이 1인 모든 칸이 최소 하나의 그룹에 포함되어야 함 |

---

### 3.2 그룹 크기와 제거 변수 수의 관계

| 묶음 칸 수 | 제거되는 변수 수 | 남은 변수 수 ($n$변수 기준) |
|:---:|:---:|:---:|
| 1개 | 0개 | $n$개 |
| 2개 | 1개 | $n-1$개 |
| 4개 | 2개 | $n-2$개 |
| 8개 | 3개 | $n-3$개 |

> 💡 **크게 묶을수록 항이 단순해집니다.** 항상 가장 큰 묶음을 먼저 찾으세요.

---

### 3.3 주항(Prime Implicant)

**주항(Prime Implicant)** 이란, 더 이상 크게 묶을 수 없는 최대 크기의 그룹에서 나오는 곱의 항입니다.

- **필수 주항(Essential Prime Implicant)**: 특정 최소항을 오직 그 주항만이 포함하는 경우, 그 주항은 반드시 선택해야 합니다.

**최소 SOP 도출 절차:**

1. 출력이 1인 모든 칸을 확인합니다.
2. 가능한 가장 큰 그룹으로 묶어 모든 주항을 구합니다.
3. 필수 주항을 먼저 선택합니다.
4. 아직 커버되지 않은 칸을 가장 적은 수의 주항으로 커버합니다.
5. 선택된 주항들의 합이 최소 SOP입니다.

---

### 3.4 예제 풀이: 3변수 K-map (Example 3.1)

> **문제**: $F(x,y,z) = \Sigma(2,3,4,5)$를 K-map으로 최소화하라  
> **정답**: $F = x'y + xy'$

**Step 1** — K-map에 1을 채웁니다.

```
        yz=00  yz=01  yz=11  yz=10
  x=0 [  0  |  0  |  1  |  1  ]   ← m2, m3 에 1
  x=1 [  1  |  1  |  0  |  0  ]   ← m4, m5 에 1
```

**Step 2** — 그룹을 찾습니다.

- **그룹 A**: $m_2, m_3$ (위쪽 행 오른쪽 두 칸) → $x=0$, $y=1$ → $x'y$
- **그룹 B**: $m_4, m_5$ (아래쪽 행 왼쪽 두 칸) → $x=1$, $y=0$ → $xy'$

**Step 3** — 결과:

$$\boxed{F = x'y + xy'}$$

> 검증: $m_2 = x'yz' \checkmark$, $m_3 = x'yz \checkmark$, $m_4 = xy'z' \checkmark$, $m_5 = xy'z \checkmark$

---

### 3.5 예제 풀이 (Example 3.2)

> **문제**: $F(x,y,z) = \Sigma(3,4,6,7)$을 K-map으로 최소화하라  
> **정답**: $F = yz + xz'$

**K-map:**

```
        yz=00  yz=01  yz=11  yz=10
  x=0 [  0  |  0  |  1  |  0  ]   ← m3
  x=1 [  1  |  0  |  1  |  1  ]   ← m4, m6, m7
```

**그룹 찾기:**

- **그룹 A**: $m_3, m_7$ → $y=1$, $z=1$ → $yz$
- **그룹 B**: $m_4, m_6$ → $x=1$, $z=0$ → $xz'$

$$\boxed{F = yz + xz'}$$

---

### 3.6 예제 풀이 (Example 3.3)

> **문제**: $F(x,y,z) = \Sigma(0,2,4,5,6)$을 K-map으로 최소화하라  
> **정답**: $F = z' + xy'$

**K-map:**

```
        yz=00  yz=01  yz=11  yz=10
  x=0 [  1  |  0  |  0  |  1  ]   ← m0, m2
  x=1 [  1  |  1  |  0  |  1  ]   ← m4, m5, m6
```

**그룹 찾기:**

- **그룹 A**: $m_0, m_2, m_4, m_6$ → 4칸, 모두 $z=0$ → $z'$  
  (왼쪽 열 $yz=00$과 오른쪽 열 $yz=10$이 인접함을 이용한 래핑 묶음)
- **그룹 B**: $m_4, m_5$ → $x=1$, $y=0$ → $xy'$  
  ($m_4$는 그룹 A와 중복되지만, $m_5$는 그룹 A로 커버되지 않으므로 필요)

$$\boxed{F = z' + xy'}$$

---

### 3.7 예제 풀이 (Example 3.4 — 4변수)

> **문제**: $A'C + A'B + AB'C + BC$를 K-map으로 최소화하라  
> **정답**: $F = C + A'B$

**먼저 식을 최소항으로 전개합니다.**

$$A'C = A'B'C + A'BC$$
$$A'B = A'BC' + A'BC$$
$$AB'C = AB'C$$
$$BC = A'BC + ABC$$

중복 제거 후 최소항 집합:

$$F = \Sigma(1, 2, 3, 5, 7)$$

(3변수 $A$, $B$, $C$ 기준으로 번호 계산)

**K-map (A=행, BC=열):**

```
         BC=00  BC=01  BC=11  BC=10
  A=0  [  0  |  1  |  1  |  1  ]   ← m0=0, m1,m3,m2
  A=1  [  0  |  1  |  1  |  0  ]   ← m5, m7
```

**그룹 찾기:**

- **그룹 A**: $m_1, m_3, m_5, m_7$ → $C=1$ → $C$
- **그룹 B**: $m_2, m_3$ → $A=0$, $B=1$ → $A'B$  
  ($m_2 = A'BC'$는 그룹 A로 커버 안 됨 → 필수)

$$\boxed{F = C + A'B}$$

### 3.8 실전예제 풀이 (실전예제 3.1~3.4)

#### 실전예제 3.1

> **문제**: $F(x,y,z) = \Sigma(0,1,6,7)$  
> **정답**: $F = xy + x'y'$

**K-map:**

```
        yz=00  yz=01  yz=11  yz=10
  x=0 [  1  |  1  |  0  |  0  ]
  x=1 [  0  |  0  |  1  |  1  ]
```

- **그룹 A**: $m_0, m_1$ → $x=0$, $y=0$ → $x'y'$
- **그룹 B**: $m_6, m_7$ → $x=1$, $y=1$ → $xy$

$$\boxed{F = x'y' + xy}$$

---

#### 실전예제 3.2

> **문제**: $F(x,y,z) = \Sigma(0,1,2,5)$  
> **정답**: $F = x'z' + y'z$

**K-map:**

```
        yz=00  yz=01  yz=11  yz=10
  x=0 [  1  |  1  |  0  |  1  ]
  x=1 [  0  |  1  |  0  |  0  ]
```

**그룹 찾기:**
- **그룹 A**: $m_0, m_2$ → 래핑($yz=00$열과 $yz=10$열 인접) → $x=0$, $z=0$ → $x'z'$
- **그룹 B**: $m_1, m_5$ → $y=0$, $z=1$ → $y'z$

(네 칸 $m_0, m_1, m_2, m_5$가 두 그룹으로 모두 커버됨)

$$\boxed{F = x'z' + y'z}$$

---

#### 실전예제 3.3

> **문제**: $F(x,y,z) = \Sigma(0,2,3,4,6)$  
> **정답**: $F = z' + x'y$

**K-map:**

```
        yz=00  yz=01  yz=11  yz=10
  x=0 [  1  |  0  |  1  |  1  ]
  x=1 [  1  |  0  |  0  |  1  ]
```

- **그룹 A**: $m_0, m_2, m_4, m_6$ → 래핑 4칸 → $z'$
- **그룹 B**: $m_2, m_3$ → $x=0$, $y=1$ → $x'y$ ($m_3$은 그룹 A에 없으므로 필수)

$$\boxed{F = z' + x'y}$$

---

#### 실전예제 3.4

> **문제**: $F = xy'z + x'y + x'z + xy$에 대해  
> ① 최소항의 합으로 표현  
> ② K-map으로 최소화

**Step 1 — SOP를 최소항으로 전개:**

$$xy'z = xy'z \quad (m_5)$$
$$x'y = x'yz' + x'yz = m_2 + m_3$$
$$x'z = x'y'z + x'yz = m_1 + m_3$$
$$xy = xyz' + xyz = m_6 + m_7$$

중복 제거:

$$F = \Sigma(1, 2, 3, 5, 6, 7)$$

**Step 2 — K-map:**

```
        yz=00  yz=01  yz=11  yz=10
  x=0 [  0  |  1  |  1  |  1  ]
  x=1 [  0  |  1  |  1  |  1  ]
```

- **그룹 A**: $m_1, m_3, m_5, m_7$ (가운데 두 열) → $z=1$ → $z$
- **그룹 B**: $m_2, m_3, m_6, m_7$ (오른쪽 두 열) → $y=1$ → $y$

$$\boxed{F = y + z}$$

### 3.9 자주 하는 실수 정리

| 실수 유형 | 내용 |
|---|---|
| 묶음 수 오류 | 3개, 5개, 6개 등 2의 거듭제곱이 아닌 묶음 시도 |
| 래핑 인접 미사용 | 맨 왼쪽-오른쪽, 위-아래도 인접함을 잊고 작은 묶음으로 끝냄 |
| 최대 그룹 미선택 | 더 크게 묶을 수 있는데 작게 묶어서 변수를 더 남김 |
| 중복 칸 거부 | 같은 칸이 두 그룹에 속하면 안 된다고 오해 (중복은 허용됨) |
| 모든 1 커버 누락 | 일부 최소항을 어느 그룹에도 포함하지 않음 |

## 4. Don't Care 조건

### 학습목표

- Don't Care 조건이 발생하는 이유를 설명할 수 있다.
- K-map에서 Don't Care를 활용해 더 단순한 최소화를 수행할 수 있다.

---

### 4.1 Don't Care란?

실제 디지털 시스템에서는 **절대 발생하지 않는 입력 조합**이 존재하는 경우가 있습니다.  
예를 들어, BCD 코드는 0~9만 사용하므로 10~15에 해당하는 4비트 조합은 입력으로 들어올 일이 없습니다.

이처럼 **출력을 정의할 필요가 없는 경우**, 해당 칸의 출력을 **Don't Care($\times$ 또는 $d$)** 로 표기합니다.

$$F = \Sigma m(\text{반드시 1인 항}) + \Sigma d(\text{Don't Care 항})$$

---

### 4.2 K-map에서 Don't Care 활용법

Don't Care 칸은 K-map에서 **$\times$** 로 표시합니다.  
최소화 시 다음 두 가지 방식으로 활용합니다.

- **그룹 확장에 활용**: $\times$ 칸을 1로 처리하여 더 큰 그룹을 만들 수 있습니다.
- **완전 무시**: $\times$ 칸이 그룹 확장에 도움이 안 되면 그냥 버려도 됩니다.

> ⚠️ **Don't Care를 반드시 어떤 그룹에 포함시킬 필요는 없습니다.**  
> 유리할 때만 사용하고, 불리하면 무시합니다.

---

### 4.3 예제 풀이

> **교재 예제**: $F(w,x,y,z) = \Sigma(1,3,7,11,15)$, $d(w,x,y,z) = \Sigma(0,2,5)$

**K-map ($\times$ = Don't Care):**

```
          yz=00  yz=01  yz=11  yz=10
wx=00  [  ×  |  1  |  1  |  ×  ]
wx=01  [  0  |  ×  |  1  |  0  ]
wx=11  [  0  |  0  |  1  |  0  ]
wx=10  [  0  |  1  |  1  |  0  ]
```

**그룹 찾기:**

- $m_1, m_3, m_5(×), m_7$ → Don't Care $m_5$를 포함해 4칸 묶음 가능  
  → $w=0$, $z=1$ → $w'z$
- $m_7, m_{11}, m_{15}$ → $yz=11$ 열 전체 → $yz$
- $m_0(×), m_1, m_2(×), m_3$ → 2칸 또는 4칸 확장 가능

**Don't Care를 활용한 최소화 결과:**

$$\boxed{F = yz + w'z}$$

**비교: Don't Care 미사용 시**

$$F = yz + w'x'z \quad \text{(더 복잡한 결과)}$$

Don't Care를 $m_5$에 활용함으로써 항이 더 단순해졌습니다.

---

### 4.4 예제 풀이 2

> **교재 예제**: $F(w,x,y,z) = \Sigma(4,5,6,7,12)$, $d(w,x,y,z) = \Sigma(0,8,13)$  
> **정답**: $F = xy' + xw'$

**K-map:**

```
          yz=00  yz=01  yz=11  yz=10
wx=00  [  ×  |  0  |  0  |  0  ]
wx=01  [  1  |  1  |  1  |  1  ]
wx=11  [  1  |  1  |  0  |  0  ]
wx=10  [  ×  |  0  |  0  |  0  ]
```

**그룹 찾기:**

- $m_4, m_5, m_6, m_7$ → $w=0$, $x=1$ → $w'x$  
  (Don't Care $m_0, m_8$을 포함해 8칸으로도 확장 가능: → $x$만 남음)  
  하지만 $m_{12}$는 별도 그룹 필요
- $m_{12}, m_{13}(d)$ → 래핑으로 $m_4, m_5$와도 연결 가능  
  → $m_4, m_5, m_{12}, m_{13}(d)$ → $xy'$

최적 조합:

$$\boxed{F = xy' + xw'}$$

#### 문제 (2)

<details>

          yz=00  yz=01  yz=11  yz=10
wx=00  [  1  |  1  |  0  |  1  ]
